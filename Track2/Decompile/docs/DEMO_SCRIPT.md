# 4-minute demo recording guide

## 0:00 - 0:25: The premise

Open Decompile. Say: "A tutorial video normally leaves an engineering team with a summary. Decompile turns it into the package they actually need to build."

## 0:25 - 0:55: Start a local job

Paste a YouTube URL and select **Generate project**. Point out the local-inference indicator and AMD ROCm-ready badge.

## 0:55 - 1:50: Watch the autonomous team work

Show the live pipeline. Narrate transcript evidence, visual understanding, product planning, and the specialist-agent handoffs. Open the terminal output and call out that all data and inference remain local.

## 1:50 - 2:40: Inspect the engineering package

Show the artifact explorer. Open PRD, architecture diagrams, API specification, Docker assets, test plan, and generated application folders. Download the ZIP.

## 2:40 - 3:20: Prove AMD readiness

Open the GPU/benchmark view. Explain ROCm/HIP runtime selection, VRAM, tokens/sec, vision latency, embeddings/sec, and the reproducible benchmark method.

## 3:20 - 4:00: Why it matters

Conclude: "Decompile lets builders learn from public video knowledge while producing private, locally generated software."

## Recording setup

Use 1440p, hide browser bookmarks, zoom to 100%, use a prepared URL, and wait for the generated ZIP action before beginning the capture. Screen recording is intentionally left to the presenter because this environment cannot capture an authenticated desktop walkthrough reliably.
