# XAI 双核融合系统 - 上手指南

## 启动

```bash
cd /Users/Admin/Desktop/mask/xai
bash /tmp/start_xai.sh
```

浏览器打开 `http://localhost:8000`

## 核心概念

XAI 是**双核并列**的 AI 工作台：

| 内核 | 用途 | 入口 |
|------|------|------|
| **Hermes**（通用推理） | 对话、分析、规划、搜索 | 统一对话台 (chat) |
| **Grok Build**（代码工程） | 写代码、构建、重构、扫描 | 对话中选 ⚙ Grok Build / 画布 grok_build 节点 |

两个内核无层级关系，Intent Router 自动分类任务并分发。

## 快速上手

### 1. 对话

在「统一对话台」输入问题即可。快捷键：
- `Cmd+Enter` 发送
- `Esc` 中止生成
- `Cmd+K` 聚焦输入框

输入框上方可切换内核：🧠 Hermes / ⚙ Grok Build / 自动。

### 2. 画布（工作流编排）

左侧面板拖拽节点到画布，连线后点击「运行」。

节点类型：input（输入）、chat（对话）、kb（知识库检索）、grok_build（代码）、condition（条件分支）、exec（命令执行）等。

右键节点可克隆/单独运行/删除。

### 3. 文件操作

- 拖拽文件到对话输入框，自动生成 `@file:` 引用
- Grok Build 生成的文件自动展示在消息中
- 画布 exec 节点可在沙箱中执行命令

### 4. 模型切换

顶栏模型名旁的模型选择器可切换：
- DeepSeek V4 Flash/V4 Pro（云端）——需要 DEEPSEEK_API_KEY
- 本地 llama.cpp 模型（9 个）——断网可用

## 主界面

- **统一对话台**：日常对话入口
- **画布**：工作流可视化编排
- **历史会话**：查看、继续过往对话
- **设置**：引擎/治理/记忆/模型/关于

## 常见问题

**Q: 对话没反应？** 检查顶栏模型是否激活（绿点=在线）。若无云端模型，切换为本地模型。

**Q: 画布节点报错？** 查看右侧日志面板，失败节点有诊断建议和重试按钮。

**Q: 如何保存工作流？** 画布顶部点击「保存」，输入名称。「我的工作流」面板可管理所有已保存画布。
