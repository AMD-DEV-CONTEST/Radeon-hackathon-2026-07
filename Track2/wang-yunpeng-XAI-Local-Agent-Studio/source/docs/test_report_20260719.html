  1. 核心 Bug — HermesAdapter.infer() 参数不匹配（严重，影响所有调用 LLM 的节点）
    所有 chat、output、condition 类型节点均抛出异常： HermesAdapter.infer() got an unexpected keyword argument 'model'
    推测 HermesAdapter.infer() 方法签名中不接受 model 参数，但调用方传入了该参数。
    影响范围：测试用例 1-4 全部因此失败，input 和 exec 节点不受影响（它们不调用 LLM）。
  2. output 节点对 exec 节点上游输出处理不足（中等）
    测试用例 4 中 exec 节点成功返回 "hello from xai workflow test\n"，但下游 output 节点仍尝试调用 LLM 并失败。
    如果 output 节点上游已是 exec 的确定结果，是否可以跳过 LLM 调用直接透传？
  3. 端口默认值不匹配任务预期（低，已规避）
    server_xai.py 默认绑定 8000 而非 8899，需通过 XAI_PORT=8899 环境变量覆盖。
    建议：在配置文件中明确端口或将 8899 设为默认。
