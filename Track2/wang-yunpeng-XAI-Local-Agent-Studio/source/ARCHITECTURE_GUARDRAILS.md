# XAI 架构防缝合怪纪律（ARCHITECTURE_GUARDRAILS）

> **地位**：本文件是架构宪法级补充。任何 AI / 人在改动 `xai/` 代码前 **必须** 先读本文件。
> **目的**：确保 XAI 是"一个大脑 + 三双手"的统一认知操作系统，而不是能力堆叠的拼凑物（缝合怪）或补丁长成的史山代码。
> **生效日期**：2026-07-21 · 主 AI 监工签发

---

## 〇、核心心智模型

```
        XAI 认知大脑（调度 / 学习 / 自适应 / 迭代）
       /      |       |        \
  左手      右手      下手        治理
 Hermes    Grok Build  知识管道    Guardian
 推理核    工程核      (本文档S3)   审批闸门
   │         │          │           │
   └─────────┴────┬─────┴───────────┘
           统一记忆层（8 层单一事实源）
```

**铁律**：三双手只提供能力，不做决策；三双手之间 **禁止直连、禁止直读对方存储**；一切经大脑统一记忆层交换。

## 一、八条硬规则（违反即打回）

### R1 收敛优于新增（最重要）
- 新能力 **必须并入现有模块**，禁止在旁边新建平行模块。
- ✅ 正确：S3 知识管道 = 升级现有 `core/kb.py`（它已在 `_CAPABILITIES` 挂名），而非新建 `core/knowledge/`。
- ❌ 错误：已有的 `kb.py` 还在，又写个 `knowledge_pipeline.py` 平行存在。
- **判定法**：新增一个文件前，先问"现有哪个模块该吞下它？"——若答不出，说明该能力本不该独立存在。

### R2 单一事实源
- 8 层记忆（`memory_core`）是 **唯一真相源**。任何模块不得自建独立向量库 / 缓存 / 影子状态。
- 三双手写入记忆必须经 `memory_bridge` API，带 `engine` 标签。

### R3 防腐层 Port/Adapter
- 所有外部 / GitHub 能力（OpenClaw / Hermes / 知识管道 …）藏在 `core/adapters/` 后面。
- 引擎只依赖 `Adapter` / `AdapterResult` 抽象（`core/adapters/base.py`），**绝不** import 具体实现细节。
- 上游升级只动 Adapter，不动引擎。

### R4 能力注册表是唯一目录
- 大脑靠 `server_xai.py` 的 `_CAPABILITIES` 发现能力，**不硬编码**。
- 新增能力：先在 `_CAPABILITIES` 挂号（kind/label/module/group/desc 齐全），再写实现。
- 实现可以是"桩"（如早期 `kb`），但挂号即承诺最终做真。

### R5 契约优先
- 前后端只经 `API_CONTRACT.md` 握手。改端点 **先改文档**，再改代码，最后补测试。
- 端点风格统一：`GET /api/<domain>/list`、`POST /api/<domain>/<action>`、`GET /api/<domain>/stats`。

### R6 "大脑叙事"测试
- 任何功能必须能在"一个大脑调度三双手"里 **一句话讲通**。
- 讲不通（"它是个独立小工具，跟大脑没啥关系"）= 该功能越界，要么并入、要么砍掉。

### R7 模块唯一 Owner + 零重复
- 每个模块有唯一归属（内核 / 记忆 / 执行 / 工程 / 治理 / 认知 / 调度）。
- **重复逻辑 = 史山种子**：发现即合并，不允许"差不多的另一份"。
- 前端模块上限 **9 个**（对话 / 画布 / 任务 / 专家团 / 自动化 / 定时 / 管理 + 双模编排 + 设置），超出即合并。

### R8 三闸为合并闸门
- 任何改动合入前必须过三闸：①功能真做到（读码核实，非自报）②自测通过（pytest）③回归不破（现有测试全绿）。
- 任一不过 = 打回，禁止"先合再修"。

## 二、商业化产品的四条体验底线

1. **一致 UX**：liquid-glass 设计语言全局统一，新增组件必须复用 `_ui.tsx` 基础件，禁止裸写样式。
2. **零阻断 bug**：核心路径（对话 / 画布 / 运行）无白屏、无死路、无未捕获崩溃。
3. **可观测**：每次操作有 trace + 日志，失败可定位、可复现。
4. **隐私闭环**：本地优先，零云依赖，新依赖必须可选（不装也能跑基础功能）。

## 三、Signal：何时你已经造出缝合怪（自查清单）

- [ ] 同一个词出现了两个实现（如两套记忆、两个 KB、两份路由表）
- [ ] 新功能要 import 另一个手的私有存储
- [ ] 能力注册表里有 kind 但实现是 `pass` / 死桩且长期不补
- [ ] 前端模块数 > 9
- [ ] `server_xai.py` 的 `elif path==` 还在增长（应在 S5 拆成 blueprint）
- [ ] 一个 PR 同时碰了 3 个以上不相关模块

命中任意一条 → 停下，先收敛，再继续。
