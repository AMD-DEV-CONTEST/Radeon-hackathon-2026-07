系统概述

XAI 控制台是一个通用 AI 操作系统中控台，将两个内核（Hermes 推理核 + Grok Build 工程核）与一个执行网关（OpenClaw）统一调度。全部本地闭环，零云依赖，模型无关。

Hermes 推理核 Grok Build 工程核 OpenClaw 网关

四层架构

A 用户交互层
纯视图，零业务逻辑
对话台 画布编排 仪表盘 任务 专家团 技能库 连接器管理 自动化 定时任务 管理

Guardian 治理闸门覆盖

规划→生成→验证 --check 自验证 --best-of-n 并行探索
C Substrate 执行网关
OpenClaw 本体

D 基础设施
8 层元认知记忆 + 模型路由
8层记忆 · 工作 短期 长期 锚点 反思 因果链 用户画像 失败修正
模型路由 (DeepSeek/Ollama/Grok) 本地知识库 (RAG) 自蒸馏 (GEPA)
