# ProofLaunch Support

Use GitHub Issues for reproducible bugs, installation failures, documentation
problems, and narrowly scoped feature requests. Use GitHub Discussions, when
enabled, for design questions and general usage help.

Before requesting support:

1. Read [JUDGE_START_HERE.md](JUDGE_START_HERE.md) for the evaluator route.
2. Follow [docs/INSTALLATION.md](docs/INSTALLATION.md).
3. Run `python scripts/validate_amd_track1_package.py`.
4. Remove tokens, private paths, customer data, and proprietary media from
   logs or screenshots.

An issue should include the operating system, Python version, GPU and driver,
ROCm/HIP version when relevant, exact revision, command, expected behavior,
actual behavior, and the smallest safe reproduction.

This project does not provide an SLA, investment advice, or authorization to
publish, send, or spend on a user's behalf.
