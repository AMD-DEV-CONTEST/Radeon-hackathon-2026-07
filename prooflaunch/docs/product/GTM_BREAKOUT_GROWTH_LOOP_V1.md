# ProofLaunch Breakout Growth Loop V1

Date: 2026-08-01  
Machine contract: `src/prooflaunch_remix/gtm_breakout_loop.py`

## Product gap closed

A channel ranking and a calendar do not explain how useful work moves from one
person to the next. The breakout loop compiles the missing earned-distribution
mechanism for every B2B/B2C lifecycle stage and budget tier. It is a measurable
hypothesis, not a virality or revenue promise.

```text
sense -> make -> seed -> convert -> learn
  ^                                  |
  |---------- next human-approved cycle
```

Each step contains a precondition, accountable owner, governed channel,
operator action, audience value, output object, success signal, stop condition,
human-release requirement and an explicit `external_action_performed=false`.

## Eight lifecycle archetypes

| Market/stage | Earned-growth archetype | Value object |
|---|---|---|
| B2B pre-PMF | founder learning relay | source-bound problem/decision memo |
| B2B launch | peer proof transfer | evidence card plus objection prompt |
| B2B growth | search evidence compound | citable explainer enriched by approved evidence |
| B2B mature | customer decision relay | evidence-and-limitations decision packet |
| B2C pre-PMF | community language loop | useful self-check before promotion |
| B2C launch | utility demo remix | proof-led short demonstration with remixable utility |
| B2C growth | search-video compound | durable answer plus short demonstration |
| B2C mature | customer ritual loop | consented before/during/after reflection format |

The seed cohorts are roles, not scraped identities. Operator capacity and the
maximum consented seed count must be supplied before release; the compiler does
not invent them.

## One-variable experiment

The primary test is bound to the existing preregistered experiment ID. It
changes only `proof_first_versus_promise_first_message_order`; offer, audience,
channel and CTA remain frozen. Required observations are unique seed exposures,
qualified engagements, voluntary pass-alongs, qualified actions and complaints
or safety stops.

The resulting amplification ratio is descriptive. UTM data, organic sharing or
an LLM judge cannot by themselves establish causal revenue lift.

## Hard boundaries

- zero-budget runs contain no paid channel or paid dependency;
- scaled runs may name the paid primary channel only as a human-activated
  amplifier; the core loop remains organic;
- no automatic publishing, outreach, spend activation or learning promotion;
- no access-control, consent, platform-policy or rights bypass;
- high-regulation runs preserve the specialist gate;
- every mutation changes the content hash and invalidates the release preview.

## Evidence

`tests/test_gtm_breakout_loop.py` executes the complete 48-case matrix, distinct
B2B/B2C mechanisms, zero-budget invariants, optional paid amplification,
single-variable experiment binding, high-regulation gating and two classes of
tamper failure. Runtime, bundle and UI tests prove that the exact artifact is
shown at the content-bound human approval boundary.

This evidence proves mechanics only. A breakout, virality, conversion or
revenue claim still requires real release observations and an eligible causal
design.
