# ProofLaunch operator console V9 — observable Agent council and creative-system diversity

Date: 2026-08-06

## Defect closed

The realtime preset path previously exposed a useful execution shell but reused too few strategic archetypes, image masters and motion beats. Different briefs could therefore look like copy variations inside one campaign template, while the Agent strategy process was invisible.

V9 changes the unit of generation from a single preset to a complete creative system. One submitted brief now compiles twelve candidate genomes across tension, hook, narrative, proof, participation, tone, visual and payoff axes. Three finalists may advance only when hook, narrative, visual and tone are pairwise distinct.

## Reused product infrastructure

V9 does not introduce a second orchestration framework. It reuses the existing content-addressed control plane in `gtm_agent_control_plane_v2.py` and the 96,000,000-combination creative kernel in `gtm_generative_execution_kernel.py`. The realtime adapter in `realtime_agent_orchestration.py` makes those capabilities observable in the two-minute evaluator path.

## Executed Graph / Loop / Harness

The live preset records six ordered specialist nodes:

1. `market-diagnosis` — `market_intelligence_agent`
2. `strategy-debate` — `strategy_council`
3. `platform-language` — `platform_copy_chief`
4. `multimodal-direction` — `image_video_director`
5. `adversarial-cut` — `red_team_jury`
6. `release-harness` — `authority_harness`

Every node returns an input hash, output hash, loop action, loop count, execution observation and external-action state. Strategy, copy and multimodal nodes execute generate/critique/repair loops. Harness rules forbid generic copy fallback, cross-industry formula reuse and automatic publish/send/spend.

The council ranks its three axis-distinct finalists against declared context: B2B/B2C decision behavior, lifecycle, budget, product surface and voice. This is an inspectable production-routing score. It is not represented as human taste, creative preference or market effect.

## Last-mile production changes

- Platform copy is generated through the selected tone grammar instead of a shared paragraph template.
- Image composition changes through ten visual grammars, including human POV, tactile artifact, kinetic type, evidence wall, diagram-as-drama, screen evidence and practical demonstration.
- Film output follows the selected narrative grammar as six explicit shots with separate beat, on-screen copy and camera/edit direction.
- The returned media manifest binds the Agent-orchestration SHA, visual grammar, narrative grammar and six-shot count to the PNG/MP4 hashes.
- The interface exposes candidate count, design space, specialist nodes, handoff hashes, context-fit routing, finalist axes and the deterministic-model boundary before asset inspection.

## Verification boundary

Mechanically observed:

- deterministic six-node Graph/Loop/Harness execution;
- twelve compiled candidate genomes and three four-axis-distinct finalists;
- context-fit scorecards and no automatic creative-winner claim;
- three PNG files, one playable MP4, signatures, dimensions and SHA-256 receipts;
- selected visual grammar and six-shot narrative grammar bound to the render manifest;
- tenant authorization, idempotent replay and named-human release boundary.

Not claimed:

- autonomous frontier-model reasoning on the preset path;
- current-click image-model inference (the source model master is pre-generated and receipt-bound);
- video-model inference (the MP4 is rendered motion design);
- human preference, proven 4A quality, publication or market effect.

The separate advanced Frontier action remains the cloud-model path and fails closed when its server credential is absent.
