# 4A GTM employee execution contract V1

This contract turns the last-mile GTM outputs into typed, falsifiable artifacts
before any professional-skill distillation is accepted. It does not treat a
prompt library, an external API answer or a schema test as a trained 4A
employee.

The verified surface enforces one strategy/audience/Claim spine across
channels while requiring distinct channel expressions. Performance hypotheses
must be pre-registered with a baseline, minimum detectable effect, direction,
mechanism and evidence locator. A/B plans isolate the changed variable, define
randomization, traffic, sample size, duration, ramp-up and SRM gates, and cannot
publish automatically. Fatigue plans combine leading and lagging signals with
a protected holdout. Audience learning requires multiple permitted signals,
human approval and an explicit sensitive-attribute denylist.

The design follows the FTC requirement for prior substantiation of objective
claims and the official Google Ads experiment guidance on a clear hypothesis,
isolated change and preselected success metrics. These sources are method
constraints, not reproduced performance evidence.
