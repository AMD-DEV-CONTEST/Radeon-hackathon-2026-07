# Example Assets

Before submitting, place here:

- `demo.jpg` — benchmark input image (512×512 or 768×768 recommended; ideally
  containing both a person and background so it can demo every feature)
- Before/after comparison images for each feature (inpaint, outpaint, remove,
  upscale, style, background)

Note: use copyright-safe material only (your own photos, Unsplash, Pixabay, etc.).
