# Hello E World — AI 人生规划师

> **核心定位**：不是算命，不是 chatbot。是基于你真实人格的**人生推演引擎**。

---

## 1. 产品演进路线

### MVP（黑客松版本）— 今天交付
```
聊天引导 → 人格建模 → What-If 推演
```
5 分钟对话，提取人格，输入一个 scenario，看 3 条平行线。

### V1（赛后 1 个月）— 3 年/5 年规划版
```
聊天引导 → 人格建模 → 3 年/5 年规划推演
```
用户输入当前状态（职业/财务/关系），AI 基于人格推演 3 条 3 年/5 年路径。
- **Path A**: 延续当前轨迹最可能的结果
- **Path B**: 如果克服盲区、发挥优势的最优结果
- **Path C**: 如果盲区主导的阴影路径

### V2（3 个月）— 多维人生仪表盘
```
输入：简历/社交媒体/自我描述
输出：人格画像 + 职业匹配 + 关系模式 + 财务倾向
```
- 上传 LinkedIn/简历 → AI 分析职业路径选择
- 输入关系困惑 → AI 基于依恋风格推演
- 输入财务目标 → AI 基于风险偏好推演

### V3（6 个月）— AI 人生教练
```
持续对话 → 动态人格模型 → 定期人生审查
```
- 每周 check-in，追踪人格变化
- 重大决策前提供平行推演
- 发现盲区后给出行为实验建议
- 匹配"与你人格互补"的合作者

## 3. 为什么 Hello E World 不是"又一个 AI 套壳"

### 核心壁垒
1. **人格模型是数据飞轮** — 用的人越多，人格推演越准
2. **不是问答，是推演** — ChatGPT 只能给你建议，Hello E World 给你路径
3. **心理学底层** — 不是随意生成，是基于决策心理学+认知偏差的严谨建模
4. **隐私 = 信任** — 全本地推理，人格数据不出设备

### 竞品分析
| 产品 | 做什么 | 缺什么 |
|------|--------|--------|
| ChatGPT | 通用建议 | 不懂你的人格，没有记忆 |
| 心理咨询 App | 情绪支持 | 不给具体路径推演 |
| 职业规划师 | 1v1 咨询 | 贵（~500/h），无法规模化 |
| 算命/占星 | 模糊预测 | 不基于数据 |
| **Hello E World** | 人格驱动的路径推演 | **唯一** |

## 4. Track 2 评分对齐

| 评分维度 | Hello E World 怎么做 |
|----------|----------------|
| **本地部署** | 100% llama.cpp + W7900，人格数据本机存储 |
| **Agent 属性** | 持续对话记忆 → 人格模型 → 多路径规划 → 结果解释 |
| **Tool Calling** | 人格提取 API → 路径推演 API → 未来可扩展日历/简历分析 |
| **隐私** | SQLite 本机，数据加密，用户完全控制 |
| **实用性** | 每个人都面临人生决策，这是刚需 |
