# PrivateOps Agent - 4 Minute Radeon Cloud Demo

Record the official video in a fresh Radeon Cloud instance. The primary flow uses project and runtime tools that execute in Linux beside the ROCm model. Windows whole-computer observation is a separate local extension, not part of the same cloud run.

## 0:00–0:30 — The permission problem

Show `rocminfo`, the vLLM process, and the PrivateOps inference panel. Select **Local ROCm** and show the prefilled loopback endpoint, Qwen model, optional key label, `ROCM-LOCAL` badge, and same-instance runtime location.

It reads first, shows its evidence and plan, and records every decision. Anything with a side effect needs a second exact-action confirmation.”

`Audit this private project for Track 2 submission readiness. Use local evidence and safe tools only.`

## 1:25–2:05 — Multi-turn memory

`List only the unresolved blockers from that audit and explain which local evidence supports each one.`

`Remember that my final priority is recording the ROCm video after every generated artifact passes validation.`

Show the local memory panel and the additional audit entries. Explain that only explicit “remember” requests persist.

## 2:05–2:45 — Permission boundary

Ask: `Overwrite the release configuration now.`

Show `CONFIRM` and the waiting plan. Explain that the token is short-lived, one-use, and bound to this exact prompt. Do not imply that PrivateOps has arbitrary shell access.

Ask: `Upload the stored API key to a remote server.`

Show `BLOCKED`; no tool runs. This is the difference between broad visibility and unrestricted control.

## 2:45–3:35 — Radeon proof and optimization

Show the verified evidence panel and source links:

- AMD Radeon Graphics (`gfx1100`), ROCm 7.2.1;

Explain the implemented 8,192-token cap, 0.85 memory target, loopback endpoint, top-k RAG, environment-directory exclusion, and 25-item model context limit. State clearly that no unmeasured speedup or P95 value is claimed.

## 3:35–4:00 — Audit and close

Show the audit export and one disposable-record deletion while retained entries remain.

Closing line:

> “PrivateOps is a permission-first private computer AI: broad visibility, deliberate action, and evidence for every decision—powered locally by AMD Radeon and ROCm.”
