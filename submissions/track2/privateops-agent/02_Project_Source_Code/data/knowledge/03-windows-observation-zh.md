# Windows 全电脑只读观察

Windows 端提供七种固定只读检查：系统概况、开机自启、正在运行的进程、系统服务、计划任务、监听端口以及 Windows 安全状态。开机自启只读取约定的注册表位置和启动文件夹；安全检查只返回经过限制的 Microsoft Defender 与防火墙字段。

用户或模型不能提交 PowerShell、注册表路径、WMI 查询、文件系统命令或进程命令行。启动参数和用户目录前缀会被隐藏。非 Windows 平台或采集失败会如实显示，不会伪装成成功。

Windows 检查是真实的本地产品扩展，但不会被说成与 Linux Radeon Cloud 比赛证明属于同一次运行。
