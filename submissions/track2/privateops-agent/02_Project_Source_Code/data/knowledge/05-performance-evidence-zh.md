# 性能证据与定向优化

真实回环模型请求测得延迟 1,511.072 毫秒、生成吞吐 32.427 tokens/s，输入 45 tokens、输出 49 tokens。完整中文 Agent 任务耗时 18.384639 秒，包含检索、规划、工具、模型生成、审计写入和响应组装。

已经实施的优化包括 8,192 token 上下文上限、0.85 GPU 显存利用率、回环传输、零温度、RAG top-k、排除环境目录、限制文件样本，以及模型最多接收 25 条列表证据。这些设置用于降低无关上下文并保持显存可预测。

项目只声明真实采集值，不虚构基线、加速比、P50、P95、显存峰值、并发或硬件压力测试数据。不可手工修改的来源是 `submission/evidence/rocm-verified/radeon-benchmark-run.json`。
