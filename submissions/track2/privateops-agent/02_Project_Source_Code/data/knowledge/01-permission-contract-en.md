# Permission Contract

PrivateOps is a permission-first private computer AI. Useful AI needs enough visibility to inspect files, startup entries, processes, services, scheduled tasks, listening ports, security posture, and project state. Visibility is not silent control.

The product promise is: broad visibility, deliberate action, evidence for every decision. Fixed read-only inspection is `safe` and may run immediately. A supported action with a side effect is `confirm`; it waits for a short-lived, one-use token bound to the exact request. Secret exfiltration, arbitrary commands, and unknown tools are `blocked`.

“Whole-computer permission” means broad supported observation. It does not mean unrestricted administrator access. PrivateOps shows retrieved evidence, the plan, tool results, permission level, memory changes, model provider, latency, and audit identifier so the user can inspect what happened.
