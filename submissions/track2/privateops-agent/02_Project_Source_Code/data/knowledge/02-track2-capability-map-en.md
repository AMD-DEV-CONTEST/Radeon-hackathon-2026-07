# Track 2 Capability Map

PrivateOps covers all five optional Track 2 capability categories in one workflow. Local RAG ranks repository-owned documents and emits stable evidence IDs. LangChain Core `StructuredTool` adapters invoke a confined registry. The planner exposes retrieval, inspection, and synthesis steps. Explicit user notes persist in local JSON memory. Permission and privacy controls combine fixed collectors, path confinement, allow-lists, exact-action confirmation, redaction, and a local audit ledger.

The application scenario is permission-first computer and project observation, not generic chat. On Windows it inspects supported operating-system state. In Radeon Cloud it inspects the private project and runtime in the same instance as the local model.
