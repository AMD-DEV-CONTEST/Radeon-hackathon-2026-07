# 权限契约

PrivateOps 是一个以权限为核心的私有电脑 AI。未来 AI 想替人干活，就需要获得查看文件、开机自启、进程、服务、计划任务、监听端口、安全状态和项目资料的权限。但是获得查看权限，不等于可以随便修改电脑。

项目的大白话原则是：看得足够多，动得足够谨慎，每一步都有证据。固定的只读检查属于 `safe`，可以立即执行；可能产生副作用的受支持动作属于 `confirm`，必须说明具体动作，并使用与该动作绑定的短时一次性令牌二次确认；泄露密码、密钥、令牌、任意命令和未知工具属于 `blocked`，不会执行。

“把整台电脑的权限给 AI”在本项目中指广泛但受支持的观察能力，不代表无限制管理员权限。页面会展示本地证据、计划、工具结果、权限判断、记忆变化、模型来源、延迟与审计编号。
