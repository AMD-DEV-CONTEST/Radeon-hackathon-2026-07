# LinkGuard AI — Track 2: Agentic AI

**Submitted by:** Muhammad Sani

## Project
An AI agent that verifies whether Nigerian grant, job, and government-opportunity 
links are genuine or scams. It fetches the linked page, reasons over domain and 
content evidence using a locally-run LLM (ROCm-accelerated on AMD Radeon GPUs), 
and returns a plain-language verdict with explanation — fully local, no third-party 
API calls.
