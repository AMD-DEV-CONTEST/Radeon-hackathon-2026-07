# Parcel Sorter ROCm / ROCm 包裹分拣

## English

Parcel Sorter ROCm is an Agent-conditioned, v21 PI0.5 VLA-routed,
scripted-motion parcel manipulation system running in Genesis on one AMD
Radeon GPU. Three delivered hybrid episodes complete 0.531-0.554 m transport
with 11.5-25.0 mm placement error. v21 routes `side_suction` by a 3/3 vote;
continuous motion remains scripted. Strict pure VLA is reported separately at
0/3. [Watch the public demo](https://www.bilibili.com/video/BV1Qkun6qEKn/).

## 中文

Parcel Sorter ROCm 是在单张 AMD Radeon GPU 上运行的 Genesis 包裹搬运系统。
Agent 生成受限任务条件，微调后的 v21 PI0.5 对抓取模式投票，脚本控制器执行连续
运动。三个交付混合回合完成 0.531-0.554 米运输，放置误差 11.5-25.0 毫米；
严格纯 VLA 单独报告为 0/3。[观看公开视频](https://www.bilibili.com/video/BV1Qkun6qEKn/)。
