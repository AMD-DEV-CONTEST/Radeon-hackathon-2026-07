# Local demo guide

This golden path requires no public network when Fake, localhost Ollama, or an approved LAN endpoint is used.

1. Submit the synthetic anomaly event.
2. Analyze it.
3. Inspect the Digital Employee, Knowledge, and Responsibility results.
4. Complete Human Review.
5. Create and start the Task.
6. Submit bounded synthetic Evidence.
7. Begin and approve Final Review.
8. Confirm the event is `CLOSED` and inspect Timeline.

The flow is: anomaly report → Analyze → Digital Employee → Knowledge → Responsibility → Human Review → Task → Evidence → Final Review → CLOSED → Timeline. Use only synthetic demo facts; no public service is required.
