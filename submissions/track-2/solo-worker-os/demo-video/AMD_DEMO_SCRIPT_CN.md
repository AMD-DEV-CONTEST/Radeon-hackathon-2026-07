**动作：** 将光标指向显示"可达：是"的状态指示器

### [0:50–1:40] 核心演示：对话与工具调用

**画面：** 聊天页面（`/chat`）

**旁白：**

> 现在让我们和智能体对话。我用自然语言描述一个新客户。

**动作：** 在聊天框中输入：

```
新客户——马库斯·里维拉，电商平台重设计，预算15000美元，截止日期8月20日
```

**旁白：**

> 智能体接收到我的消息。FunctionRouter——一个两层路由引擎——在毫秒级将其分类为"通用"子智能体任务。然后智能体自动调用了"创建项目"工具。

**动作：** 等待智能体响应，展示工具调用标签出现。

> 项目已创建。智能体从一句话中提取了客户姓名、项目类型、预算和截止日期——不需要填表单，不需要手动输入。
>
> 现在让我们为这个项目生成一份合同。

**动作：** 输入：

```
为马库斯的项目生成一份合同
```

**旁白：**

> 同一个对话中。智能体调用"生成合同"工具。一份完整的服务协议被生成——包含付款条款、工作范围和时间线——全部从我们刚才创建的项目中链式生成。

**动作：** 展示合同文本在聊天中流式输出。

## 录制技巧

1. **先演练一遍**，不用录，熟悉流程和时间
2. **工具调用时停顿**，等智能体响应完再继续说
3. **录屏前清空聊天历史**，确保演示干净
4. **打字时放慢**，让观众看清输入内容
5. **如果智能体响应慢**（6-7秒），这是正常的——说明推理在GPU上跑，不是预录的
6. **结尾留2秒静音**再停止录制
7. **语气保持平稳自信**，像在向客户介绍产品一样

## 备选方案：如果没有专用GPU实例

如果你无法在 Radeon Cloud 上启动专用 vLLM 实例（由于速率限制），`developer.amd.com.cn/radeon/api/v1` 的免费模型API仍然运行在 AMD Radeon GPU 硬件上。在演示视频中，你可以：

1. 展示设置页面的健康探针（证明 AMD GPU 可达性）
2. 强调API端点是 AMD 自有平台，运行在 Radeon GPU 上
3. 在文档中说明代码同时支持专用 vLLM 实例和共享API

不过，**为了最大程度的合规**，请尽量启动专用 vLLM 实例。速率限制在1小时后重置。
