Security boundaries

  • Identity: Private SSH host keys require explicit confirmation and fail closed on change.
  • Secrets: Private-key bytes are never stored; live URLs, ports, bearer secrets, target paths, process facts, and raw output stay session-local.
  • Authority: Deployment registers a provider but never selects it for the user.
  • Location: Private SSH is a confirmed Linux server; Local WSL is a distinct selected WSL2 distribution.
Evidence boundary

No comparative speedup. No generic Radeon support. No accepted Local WSL hardware.
