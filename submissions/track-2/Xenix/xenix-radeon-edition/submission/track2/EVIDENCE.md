the claim, the reviewable evidence, the narrow boundary of that evidence, and
what the submission does **not** claim. Source links point only to durable public
repository material; no internal task workspace is part of the submission.

## Evidence required before final pull request

- A successful 3–5 minute English demo showing the actual UI, complete Hero
  workflow, correct Dataset, policy citation, and grounded multi-turn follow-up.
- Safe request-path evidence that pairs real inference with the declared Radeon,
  `gfx1100`, and ROCm 7.2.1 cell without exposing endpoints or credentials.
- A timestamped repeated same-cell performance bundle. If a valid
  baseline/optimized comparison is unavailable, remove all uplift language and
  report only the architecture and fixed configuration.
- A clean verification record for the exact source commit submitted.
- The primary and supplementary public video URLs recorded in the
  [Submission Checklist](SUBMISSION_CHECKLIST.md).
