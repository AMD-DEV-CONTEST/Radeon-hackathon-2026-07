## Outcome

functional blockers reported against PR #34 head `e8fbfff`:

1. expired, unconfirmed deletion requests are atomically persisted as
   `EXPIRED`, audited, and no longer block a new request for the same asset;
2. E7 no longer treats E6's composite `ApprovalRecord.route_draft_hash` as the
   renderer identity. The frozen adapter consumes the exact record and input
   snapshot generated by E6 commit
   `07c4dc8995ad8145f6e5fbb7319b8698978e879a`.

identity are now distinct bindings. HTML, Markdown and JSON expose all three.
