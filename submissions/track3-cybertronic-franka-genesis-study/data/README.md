# Data

This demo does not require an external dataset. The moving fruit target is generated procedurally inside `src/franka_fruit_follow.py`.

No large datasets should be committed to this repository. If future experiments require data, provide generation scripts or download links here.

# 数据说明

本 Demo 不依赖外部数据集。水果目标轨迹由 `src/franka_fruit_follow.py` 在运行时程序化生成。

请不要把大型数据集直接提交到仓库。如后续实验需要数据，请在此提供生成脚本或下载链接。
