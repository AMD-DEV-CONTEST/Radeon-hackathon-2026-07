SignalForge is a private, local-first research desk for independent investors. Public filings, investor-relations material, macroeconomic series, and market observations are abundant. What is scarce is a disciplined process that keeps facts, calculations, assumptions, counterarguments, and uncertainty separate.

SignalForge helps a user understand how a business earns money, examine financial quality, connect economic forces to explicit transmission mechanisms, compare companies, inspect valuation scenarios, and identify what would invalidate a thesis. It does not predict prices, execute trades, or provide personalized investment instructions.

The architecture separates interpretation from financial authority. A typed Go control plane owns scope, evidence authorization, tool permissions, calculations, lineage, review gates, and publication. Local Gemma performs core review and final synthesis on an AMD Radeon GPU through ROCm. Optional organizer-provided Radeon API specialists add bounded context in parallel, but they do not own the final answer. If that route fails, the authorized local model can recover. If the core local model is unavailable, SignalForge fails closed.

This is a real, non-sealed journey captured from the current candidate on AMD Radeon Cloud. The user asks SignalForge to compare Microsoft and NVIDIA as long-term businesses under higher-for-longer rates and slower AI infrastructure spending. These scenario controls are explicit assumptions, not forecasts.

The Interpreter closes intent and scope. The Orchestrator builds a typed plan and schedules two specialist waves, with at most four roles running concurrently. Business strategy, financial quality, economics, valuation, market behavior, and accounting each receive bounded evidence and a strict contract. They exchange typed packets and references, not unrestricted chat transcripts.

The live plan shows the execution state without exposing hidden reasoning. A first review narrows unsupported claims and approves a safer subset. A second evidence review removes claims that cannot cross the publication boundary. Only then does the local final analyst synthesize the released research case.

Mission Control reconciles the same run and trace identities shown in the workspace. This accepted demonstration recorded twenty model-call attempts across local ROCm and the provided Radeon API, six completed context packets, eighteen deterministic engine calls, and five governed reviews. Four failed provider attempts were recovered before release. Prompts, responses, source bodies, credentials, and private reasoning are absent from the public telemetry.

The language model is not the numerical system of record. SignalForge applies a Numerical Silence contract. Models may interpret verified relationships, but Go owns every authoritative value, period, unit, formula, comparison direction, and quantitative rendering.

The Proof layer makes that boundary inspectable. This evidence card identifies a primary source, its section, as-of date, citation target, and content hash. The DCF receipt exposes the formula version, canonical input references, verified outputs, invariants, evidence references, and replay hash. A fluent model cannot silently rewrite those values.

The completed research case uses progressive disclosure. The main answer remains readable, while evidence, assumptions, counterevidence, receipts, and limitations stay one interaction away. Follow-up questions preserve company, scenario, and point-in-time scope. Durable case memory is opt-in, stores only the released safe projection, and supports inspect, export, and delete.

Radeon optimization was measured on complete product journeys rather than an isolated token-speed benchmark. The public development tournament contains eight non-sealed journeys per mode. Every compared mode passed eight of eight runtime and release contracts. Against the two-worker baseline, four local workers achieved 2.7777 times aggregate speedup and a 64.37 percent p50 reduction. The hybrid profile achieved 2.0756 times aggregate speedup, accepted twenty Radeon API calls, and recovered one failed remote call. These are workload-specific development results, not universal accuracy or throughput claims.

Failure behavior is equally explicit. In a bounded fault-injection run, loss of the Radeon API recovered through local ROCm and completed a governed release. When the core local model was unavailable, the system stopped in twenty-two milliseconds, made zero model calls, and released no answer.

SignalForge combines local specialist intelligence with deterministic financial truth. The result is not another financial chatbot. It is a private, inspectable research process built on AMD Radeon and ROCm, with evidence strong enough to challenge and a release gate strict enough to say no.
