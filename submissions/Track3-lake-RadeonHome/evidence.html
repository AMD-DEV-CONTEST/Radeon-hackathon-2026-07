Technical Innovations

1. Language → Physical Execution

The only Track 3 entry with a natural-language interface. A local Qwen3-4B model converts free-form instructions into validated task plans. The LLM never emits joint commands — a deterministic safety boundary separates language understanding from physical control.

2. Safe MJCF Mobile Migration

Official fixed-base Franka MJCF asset migrated to a collision-aware planar mobile base. Three failed geometries are retained as regression evidence, not hidden. Generated planar root joints replace the fixed tabletop-mount collision while preserving all arm, hand, and fingertip collisions.

3. Slip Detection + Recovery

Real-time contact-force monitoring during transport triggers autonomous retry on slip detection. Unlike success-only filtering, failures are recorded and analyzed — a matched ablation compares gripper-only carry vs. support-tray transport.

4. Honest Evaluation

All failed trials and limitations are explicitly reported. Identical-seed ablation comparing three transport strategies. Tall-carton unloading is documented as a known failure mode. Negative results are published, not cherry-picked.

Limitations (Explicitly Disclosed)

  • The physical controller is deterministic, not a trained policy — this is stated explicitly, not hidden
  • Simulator semantic locations remain privileged inputs
  • Collision-corrected multi-profile smoke test uses one seed per profile
  • Tall-carton unloading is a documented failure mode
  • Support-tray transport matched ablation: gripper-only 2/2, tray carry 0/2 — this negative result is published
