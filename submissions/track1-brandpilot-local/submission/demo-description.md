# Demo description

## Suggested title

BrandPilot Local - Review-first campaign creation on AMD Radeon and ROCm

## Suggested public description

BrandPilot Local is a responsive, local-first creative studio prototype for
turning a rights-cleared product image and campaign brief into reviewable
marketing concepts. Built for Track 1 of the AMD AI DevMaster Hackathon, it
combines campaign configuration, multiple creative directions, output formats,
copy, responsible disclosure, and persisted human review.

This demo distinguishes the local mock product workflow from recorded Radeon
evidence. Real SDXL image-to-image inference and one authenticated FastAPI
loopback generation were verified on AMD Radeon with ROCm. The final public
browser edge remained blocked because the official platform-assigned tunnel
hostname did not resolve in public DNS; no full browser-to-Radeon E2E claim is
made.

Repository: https://github.com/kmt9967/brandpilot-local
