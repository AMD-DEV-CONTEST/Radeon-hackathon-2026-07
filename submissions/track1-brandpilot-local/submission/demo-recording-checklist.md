# Demo recording checklist

## Before recording

- [ ] Run final automated validation at the exact commit.
- [ ] Start the local backend and production frontend only.
- [ ] Confirm mock is the default and experimental mode is disconnected.
- [ ] Reset local project storage to a clean demonstration state using the
      documented local workflow only.
- [ ] Use `examples/browser-test-product.png` and no client asset.
- [ ] Close private tabs, notifications, email, chat, account menus, and file explorers.
- [ ] Set 1920 x 1080 recording and 100% browser zoom.
- [ ] Confirm microphone level and quiet background.
- [ ] Place sanitized evidence PNGs in a dedicated presentation/recording folder.

## During recording

- [ ] Keep `Local UI demonstration` visible over live local product footage.
- [ ] Keep `Mock campaign concept` visible over mock results.
- [ ] Keep `Recorded Radeon evidence` / `Verified Radeon output` visible over evidence.
- [ ] State that the real Radeon image was generated in a prior verified session.
- [ ] Do not imply a live Radeon generation.
- [ ] Show review action and refresh persistence.
- [ ] State the official DNS blocker exactly once and show shutdown proof.
- [ ] Avoid dead time, rapid cursor movement, and tiny text.

## Privacy and claims

- [ ] No token, hostname, tunnel URL, account/instance ID, email, private URL,
      browser profile, raw log, internal path, or private support message appears.
- [ ] No production, permanent-hosting, full browser-E2E, preservation,
      commercial-clearance, training, or unsupported benchmark claim appears.
- [ ] Captions match the final narration and labels.

## Export and publication

- [ ] Duration is between 3 and 5 minutes.
- [ ] 1080p video is visually and audibly reviewed from start to finish.
- [ ] Captions are attached or burned in and readable.
- [ ] Link permissions allow judges to view without requesting access.
- [ ] Description links the official submission PR and claim boundary.
- [ ] Publication/upload is performed only by the user or with explicit approval.
