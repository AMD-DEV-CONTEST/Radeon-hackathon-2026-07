# Demo recording plan

## Target length

Three to five minutes, recorded entirely from the local application and
sanitized repository evidence. No Radeon instance is required or permitted.

## Sequence

1. **Homepage — 20 seconds.** State the user problem and local-first,
   review-first promise.
2. **Creative Studio — 35 seconds.** Upload a rights-cleared example, enter the
   campaign brief, choose Luxury, and show responsive controls.
3. **Mock generation — 35 seconds.** Run the default local mock flow and point
   directly to every `Mock` disclosure. Do not call the concepts GPU outputs.
4. **Results and review — 40 seconds.** Show the results board, edit/review
   controls, approve one concept, refresh, and show persistence.
5. **Responsive quality — 20 seconds.** Show desktop and narrow/mobile layouts,
   including the navigation and studio flow.
6. **Architecture — 30 seconds.** Explain local Next.js, FastAPI, serialized
   experimental worker, protected images, and temporary session-only runtime
   connection.
7. **Real Radeon evidence — 45 seconds.** Show the already verified AMD Radeon,
   HIP/ROCm, exact SDXL model/revision, real output image, timing, VRAM, and
   authenticated loopback evidence from earlier sessions.
8. **Official edge blocker — 25 seconds.** Show the sanitized Session 3 DNS
   classification and no-active-instance proof. Explain that TLS was preserved
   and unofficial tunnels were rejected.
9. **Roadmap — 20 seconds.** Close with product-preservation evaluation using
   IP-Adapter plus masking/compositing after approved transport is available.

## Recording safeguards

- Hide browser chrome and account UI.
- Use no live tunnel hostname, token, authorization header, cloud identifier,
  or terminal session.
- Keep mock and real Radeon evidence visually and verbally distinct.
- Do not imply the earlier real output came through the browser application.
- Record locally; inspect every frame before submission.
