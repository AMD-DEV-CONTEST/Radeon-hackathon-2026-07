# Radeon Cloud session 2c evidence

This directory contains sanitised evidence from the single Session 2c
browser-completion attempt.

No job ran because the active official tunnel's assigned public hostname did
not resolve from Chrome or Windows. Consequently, no remote metadata, generated
image, review state, or evidence bundle was downloaded.

Retained evidence:

- `screenshots/10-no-active-instance.png`: cropped confirmation that no Radeon
  instance remained after shutdown.
- `screenshot-hashes.json`: SHA-256 for the retained screenshot.

Every retained screenshot receives a SHA-256 entry. Do not store tunnel URLs,
access tokens, authorisation headers, emails, account or instance identifiers,
internal hosts, private paths, browser state, raw logs, environment dumps,
wheelhouse files, model caches, weights, or client assets here. This evidence
makes no generation, public authentication, CORS, or browser-E2E success claim.
