RADEON HACKATHON 2026-07 · TRACK 2

IELTS OS · Private AI Study Agent

Team OpenSpark
Local-first · AMD Radeon GPU · No cloud lock-in

A local-first IELTS study app with a built-in private AI agent. The tutor reads the learner's own four-skill answers, vocabulary book, material index and persistent learning memory, then turns each attempt into a review and prioritized next drill. Inference runs on AMD Radeon GPUs through Radeon Cloud or a fully local ROCm backend.

INFERENCE-SPEED LESSONS (FREE TIER, AUG 2026)

  • Qwen3.6 hidden thinking exhausts the token budget — disabled via chat_template_kwargs.enable_thinking=false.
  • Gateway hard-cuts at ~120 s — answers capped at 384 tokens with concise system prompts.
  • Transient 5xx under load — one server-side retry plus one client retry; honest error surfacing.
