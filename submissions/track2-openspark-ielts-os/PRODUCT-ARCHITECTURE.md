# IELTS OS 产品架构草案

## 产品判断

这个应用不应该只是复刻扇贝。扇贝的强项是成熟内容、打卡、词书、课程入口和 AI 辅助；我们的优势应该是把你的材料、错题、Obsidian 知识库和 AI 反馈合成一个个人 IELTS OS。

核心价值：

- 省钱：先用已有资料、开源技能和本地题库，不依赖每个模块单独订阅。
- 更贴合你：所有练习、错题、生词、作文问题、口语弱点都归到同一个学习档案。
- 能追溯来源：每个词、错题和 AI 建议都要知道来自哪篇文章、哪段音频、哪篇作文、哪次口语。
- 能复习：不是看完就没了，而是进入统一复习队列。
- 能沉淀：重要内容可以导出到 Obsidian，形成知识图谱和错题库。

## 统一数据模型

所有模块都应该沉淀成 `LearningItem`，这样单词、错题、作文问题和口语问题才能被同一套复习系统管理。

```json
{
  "id": "reading-c20-p1-q4",
  "type": "word | phrase | reading_error | listening_error | writing_issue | speaking_issue",
  "title": "significant",
  "source": {
    "module": "reading",
    "material": "IELTS OS 模拟精读",
    "location": "Passage 1, paragraph 1"
  },
  "evidence": "This approach requires significant evidence from local councils.",
  "feedback": "significant = important / substantial，可用于同义替换。",
  "memoryState": "new | learning | due | mastered",
  "nextReviewAt": "2026-06-22"
}
```

## 模块拆解

### 单词

数据来源：雅思词书、阅读点词、听力错词、作文/口语 AI 反馈中的高频弱词。

需要功能：每日新词、复习词、总清单、生词本、单词详情、美音发音、音标、原创例句、同义替换、加入生词本、标记太简单。

关键交互：在任何句子里点词，底部弹出释义、音标、美音喇叭和加入生词本。

### 阅读

数据来源：内置原创示例文章、用户本地 PDF/文档、后续可接网页文章或公开 IELTS 话题材料。

需要功能：文章精读、点词查义、题目练习、错题归因、同义替换链、段落定位、AI 解释。

错题来源：做阅读题后的选项记录。错因按题型、定位失败、同义替换失败、主旨判断失败分类。

### 听力

数据来源：用户本地音频、转写稿、用户导入音频。

需要功能：分段播放、倍速、听写、答案核对、错词归因、时间戳复听。

错题来源：填空错误、拼写错误、数字/日期错误、复数漏写、信号词没听到。

### 写作

数据来源：用户输入、拍照 OCR、题库作文题。

需要功能：Task 1/Task 2 分类、AI 批改、评分维度 TR/CC/LR/GRA、逐句润色、错误类型统计、优秀表达沉淀。

错题来源：AI 批改结果中的语法、词汇、结构和论证问题。

### 口语

数据来源：Part 1/2/3 题库、用户录音、转写文本。

需要功能：题库练习、录音、转写、AI 追问、流利度/词汇/语法/发音反馈、素材库。

错题来源：回答中的卡顿、语法错误、低级词替换、跑题、答案过短。

### AI

AI 不应该只是聊天页，而是每个模块的上下文助手。

使用方式：

- 阅读：解释句子、生成定位提示、拆同义替换。
- 听力：解释为什么听错，生成跟读/听写小练习。
- 写作：按评分标准批改，给可执行修改建议。
- 口语：模拟考官追问，给自然表达替换。
- 单词：结合当前文章解释词义，而不是只给字典释义。

### Obsidian

Obsidian 是长期知识库，不是每日练习入口。

导出内容：

- 生词卡：词义、音标、原创例句、同义替换、来源。
- 阅读错题：题目、你选的答案、正确答案、错因、定位句。
- 听力错题：音频时间戳、原答案、你的答案、错因。
- 写作问题：原句、问题类型、修改建议。
- 口语素材：题目、回答、AI 反馈、可复用表达。

## MVP 路线

1. 做通“点词查义 -> 加入生词本 -> 每日复习”的闭环。
2. 导入一小套阅读文章和题目，让错题本真实产生数据。
3. 做听力最小闭环：音频分段、答案输入、错因记录。
4. 接入 OpenAI API 做写作批改和口语模拟。
5. 做 Obsidian 导出，把学习记录变成可复用知识库。

## 当前 Demo 已验证的底座

- `data/wordbook.json`：词书、每日队列、词义、音标、原创例句、关联词。
- `data/reading.json`：阅读文章、可点词、题目、选项反馈。
- `data/wrong-questions.json`：错题样例。
- `localStorage`：生词本本地保存。
- `SpeechSynthesisUtterance`：本机美音朗读。

下一步不应该急着扩 50 个页面，而是先把一套真实材料导入成结构化数据，保证每一次点击都能留下可复习的学习记录。
