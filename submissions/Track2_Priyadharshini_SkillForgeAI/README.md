# SkillForge AI

## Track
Track 2: Development & Local Deployment of Private AI Agents

## Project Description

SkillForge AI is an AI-powered career assistant that helps students and developers analyze skills, detect skill gaps, generate personalized learning roadmaps, recommend projects, and provide career guidance.

## Application Scenario

Students and developers need personalized career guidance. SkillForge AI provides AI-based recommendations using intelligent agents.

## Core Capabilities

- Career Analysis Agent
- Skill Gap Detection Agent
- Roadmap Generation Agent
- Project Recommendation Agent
- AI Chat Assistant
- Conversation Memory

## Technology Stack

- Python
- Flask
- SQLite
- HTML
