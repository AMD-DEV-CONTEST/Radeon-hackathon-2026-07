# 部署与运维指南

## 一、环境要求

- **GPU**：AMD Radeon GPU（推荐 RX 7900 XTX / W7900，16GB+ 显存），或 Radeon Cloud 云端 GPU
- **ROCm**：6.x 版本（AMD Linux 环境）
- **Python**：3.10+
- **LLM**：Qwen 系列 GGUF 模型（如 qwen3:8b）

## 二、本地部署步骤

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动推理服务（Ollama，自动用 ROCm）
ollama pull qwen3:8b
ollama pull bge-m3
ollama serve

# 3. 导入文档 + 启动网页
python main.py ingest data/docs/
python main.py ui    # 访问 http://localhost:7860
```

## 三、Docker 一键部署

提供 docker-compose 编排：Ollama 推理服务 + Agent 应用两个容器。在 AMD + ROCm 主机上取消 ollama 服务的 `devices` 和 `group_add` 注释，即可让 GPU 进入容器，直接享受 AMD 加速。数据目录挂载在 `./data`，完全本地。

## 四、Radeon Cloud 云端部署

1. 在 Radeon Cloud 控制台申请 GPU 实例（选择 ROCm 镜像）
2. 上传部署包，执行 `deploy_rc.sh`：
   - 安装 ROCm 环境与依赖
   - 拉取 GGUF 模型（Q4_K_M 量化）
   - 以 vLLM / llama.cpp 启动推理服务
   - 启动 Agent 应用并暴露端口
3. 用 `rocm-smi` 验证 GPU 利用率，运行基准测试脚本收集性能证据

## 五、运维监控

- **GPU 监控**：应用内置 GPU 监控面板，每 2 秒刷新利用率、显存、温度、功耗；离线环境自动降级为演示数据。
- **健康检查**：系统信息浮层展示后端、模型、服务地址、工具加载状态。
- **日志**：运行轨迹面板记录每一步工具调用与核查结论，便于排查与演示。

## 六、隐私与安全

所有数据（文档、向量库、长期记忆）均存储在本地 `data/` 目录，不向任何外部服务发送请求。断网环境下功能完全可用。
