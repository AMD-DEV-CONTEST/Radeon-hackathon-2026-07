# AMD AI DevMaster 黑客松 项目说明

## 项目名称
本地私有 RAG 知识库智能助手（Private RAG Agent）

## 核心特性
1. 完全离线部署：所有推理在本地 AMD Radeon GPU 上完成，不依赖任何外部 API
2. 数据不出本机：用户文档存储在本地，隐私安全
3. 支持多种文档格式：PDF、Word、Markdown、Excel、PPT
4. 混合检索：向量语义检索 + BM25 关键词检索 + cross-encoder 重排
5. 多 Agent 协作：任务分解 → 并行研究 → 事实核查 → 综合
6. 引用可追溯：每个回答附带来源引用，点开即可查看原文高亮

## 技术栈
- 推理后端：llama.cpp(HIP) / Ollama(ROCm) / vLLM(ROCm)，可配置切换
- 向量数据库：ChromaDB（本地持久化）
- Embedding 模型：bge-m3（1024 维中文向量）
- 重排模型：bge-reranker-v2-m3（cross-encoder）
- LLM 模型：Qwen 系列
- 前端：FastAPI + SSE 流式 + 原生 HTML/CSS/JS（无框架依赖）

## AMD 优化
- 使用 ROCm 开源软件栈
- 支持 GGUF 量化（Q4_K_M、Q8_0），显存占用可减 70%
- embedding / 重排模型模块级共享，多 Agent 并行只加载一份
- 内置 GPU 监控面板（利用率/显存/温度/时钟/功耗）

## 部署要求
- AMD Radeon GPU（推荐 RX 7900 XTX / W7900）
- ROCm 6.x 环境
- Python 3.10+
- 支持 Radeon Cloud 云端部署（vLLM + ROCm）
