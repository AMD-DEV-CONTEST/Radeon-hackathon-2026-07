# 项目技术架构白皮书

## 一、项目定位

本项目是一个完全离线的本地私有 AI 智能体，面向企业和个人用户的知识管理场景。核心价值是：**数据不出本机**——文档解析、向量化、检索、推理全部在本地完成，不依赖任何云端 API，断网环境依然可用。

## 二、整体架构

系统采用四层架构：

### 1. 前端展示层
使用 FastAPI 提供 SSE 流式接口，前端为原生 HTML/CSS/JavaScript，无任何前端框架依赖。界面采用精密仪器风格：深色表面阶梯、发丝线边框、AMD 红强调色。功能包括流式对话、运行轨迹面板、GPU 监控面板、来源深潜抽屉（点击引用即可查看原文并高亮查询词）。

### 2. Agent 编排层
- **单 Agent 模式**：感知 → 规划 → 工具调用 → 回答 → 引用校验的完整闭环。内置 Planner 任务规划器，遇到复杂问题自动拆解为多步骤执行。
- **多 Agent 协作模式**：Decomposer 把问题拆成 n 个相互独立的子问题 → n 个 Researcher 并行检索知识库 → Fact-Checker 对每份子报告做事实核查 → Synthesizer 只依据通过核查的内容综合成最终答案。
- **记忆管理**：多轮对话历史 + 长期记忆文件，可记住用户偏好。
- **工具注册**：rag_search（检索）、read_doc（读全文）、list_docs（列文档）、summarize（摘要）等。

### 3. RAG 检索层
检索管线为业界标准组合，全程本地：
1. **查询改写**：用 LLM 把用户问题改写成更利于检索的多个变体
2. **向量检索**：ChromaDB + bge-m3 embedding，捕获语义相似
3. **BM25 关键词检索**：捕获专有名词、缩写、精确术语
4. **RRF 融合**：Reciprocal Rank Fusion 把多路结果按排名加权融合
5. **Cross-Encoder 重排**：bge-reranker-v2-m3 对 (query, doc) 联合打分，显著提升 Top-k 精度

### 4. 推理后端层
通过 llm.py 统一封装多后端：Ollama（开箱即用）、llama.cpp（GGUF + ROCm 全 GPU offload）、vLLM（高并发场景）。

## 三、可信度验证机制

这是本项目区别于普通 RAG 的关键设计：
- **Groundedness 校验**：把回答逐句拆解，用 3-gram 重叠算法与检索到的文档原文比对，计算每句话的证据支撑度。
- **引用真实性校验**：核对回答中标注的 [来源:文件名] 是否真实存在于知识库。
- **LLM-as-Judge**：多 Agent 模式下，用 LLM 逐条判断事实性陈述是否被来源支撑。
- 最终回答附带**可信度徽标**（已支撑 / 部分支撑 / 证据不足），让用户清楚看到哪些内容有据可查。
