# Private RAG Agent 技术白皮书

## 一、系统架构

本项目是一个完全本地运行的私有 RAG Agent，采用"混合检索 + 多智能体协作 + 引用校验"三段式架构。

### 推理层
- LLM 推理默认使用 Ollama + Qwen3 系列模型，支持 GGUF 量化（Q4_K_M、Q8_0）
- 在 AMD Radeon Cloud 环境下自动切换 vLLM(ROCm) 后端，支持大模型部署
- 多后端统一接口，通过 config.yaml 一键切换

### 检索层
- 混合检索管线：BM25 关键词检索 + 向量语义检索（ChromaDB）+ Reciprocal Rank Fusion 分数融合
- 使用 bge-m3 中文 embedding 模型，支持跨语言检索
- cross-encoder 重排（bge-reranker-v2-m3）显著提升 Top-K 精度
- 查询改写：LLM 自动扩展检索词，提升召回率

### 智能体层
- 单 Agent：感知 → 规划（Planner）→ 工具调用 → 回答
- 多 Agent 并行：任务分解器 → 并行研究者 → 事实核查者 → 汇总者
- 每个工具调用都在界面上实时可视化展示

### 可信层
- 引用校验：每个回答自动检查引用来源是否真实存在
- Groundedness 评分：逐句标注"已支撑 / 部分支撑 / 无支撑"
- 低置信度回答会明确提示用户核对原文，绝不编造

## 二、隐私与安全

1. 所有推理在本地 AMD Radeon GPU 完成，数据不出本机
2. 支持完全离线运行，不依赖任何外部 API
3. 文档存储在本地向量数据库，支持随时删除
4. 无云端上传、无遥测上报

## 三、AMD 优化

- 使用 ROCm 开源软件栈，实现 CPU 到 GPU 的推理加速
- 多智能体并行任务在 GPU 上并发排队执行，大幅缩短总耗时
- 支持 AITER（AMD 官方算子库）等 ROCm 优化
- GPU 利用率、显存、温度、功耗实时监控面板

## 四、部署要求

- 本地推荐：AMD Radeon RX 7900 XTX / W7900，ROCm 6.x
- 云端：AMD Radeon Cloud 工作区，vLLM + ROCm
- Python 3.10+
