## 二、现场演示流程（推荐 3~4 分钟）

1. **开场**：打开 `localhost:7860`，展示空状态动画插画（QUERY→VECTOR DB→GROUNDED）
2. **导入文档**：点"导入文档"上传 1-2 个文件，展示"6 文档 / 15 片段"计数
3. **单 Agent 问答**：问"我的项目用了什么技术栈？"
   - 强调：右侧运行轨迹面板实时显示 `rag_search` 工具调用
   - 强调：回答带引用来源卡片，点开抽屉看原文高亮
4. **多 Agent 并行**：切"多 Agent 并行"模式，问"分析这个项目的技术栈、AMD优化点和部署方式"
   - 强调：计划面板 3 个子任务 + 进度条
   - 强调：3 个子 Agent 并行检索、事实核查卡片（grounding 分数）
   - 强调：汇总只依据通过核查的内容
5. **GPU 监控**：切到 GPU 面板，展示利用率/显存/温度曲线
6. **收尾**：强调"检索可追溯、回答可核查、数据不出本机"

## 三、多 Agent 模式演示小抄（背诵要点）

```
分解 → 并行研究 → 事实核查 → 综合

"为什么用多 Agent？复杂问题拆成 n 个独立子问题，
在 AMD GPU 上多个推理并发排队，串行转并行，
墙钟时间大幅下降——这是 AMD 加速的核心价值。"

"为什么核查？模型可能编造。我们把每句话和检索到的
原文做重叠度比对，不支撑的如实标注。看这个核查卡片，
grounding 0.5+ 就是已支撑，引用文件必须真实存在。"
```
