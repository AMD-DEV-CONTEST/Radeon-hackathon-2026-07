# 演示视频脚本（赛道 2 · 本地私有 AI Agent）

> 时长目标：3~4 分钟 · 分辨率 1920×1080 · 开场 3 秒内亮出项目名与"完全离线"卖点

---

## 镜头 1 · 开场（0:00–0:15）

**画面**：深色桌面 → 浏览器打开 `localhost:7860`，停在空状态页
（动画 RAG 流水线插图：QUERY → VECTOR DB → GROUNDED）

**旁白**：
> 这是 Private RAG Agent——一个完全离线的本地私有 AI 智能体。
> 你导入的每一份文档，都只在本机处理，数据不出设备。

**字幕**：🔒 数据 100% 本地 · 断网可用

---

## 镜头 2 · 文档入库（0:15–0:45）

**操作**：侧边栏"导入文档"→ 选择技术白皮书 + 示例项目 → 右上角出现
"3 份文档 · 5 片段"

**旁白**：
> 支持 PDF、Word、Markdown、Excel、PPT。导入后自动完成解析、切片、向量化。
> 三种文件格式，一个点击，全部进入本地知识库。

**屏幕标注**：切片过程 flash 出 `chunk_text 512+64` 字样

---

## 镜头 3 · 单 Agent 问答（0:45–1:30）

**操作**：输入"我的项目用了什么技术栈？"→ Enter

**画面重点（三连拍）**：
1. 右侧**运行轨迹面板**逐条弹出 `rag_search` 工具调用
2. 回答流式打出，末尾出现**引用来源卡片**（文件名 + 相关度条）
3. 点击引用 → **来源深潜抽屉**滑入，原文中**查询词高亮**标红

**旁白**：
> 每次回答前，Agent 先检索知识库——混合检索把语义向量和关键词 BM25 融合，
> 再用 cross-encoder 模型重排，确保最相关的片段排在最前。
> 每条回答都带可点击的引用，点开就能看到原文出处，还能看到关键词在原文中的高亮位置。

---

## 镜头 4 · 多 Agent 并行（1:30–2:30）

**操作**：切到"多 Agent 并行"模式 → 输入"分析这个项目的技术栈、优化点和部署方式"→ Enter

**画面重点（本片高潮，慢镜头）**：
1. 顶部出现**计划面板**：3 个并行子任务 + 进度条 `1/3 → 2/3 → 3/3`
2. 右侧活动面板同时出现 **3 个子 Agent 的实时检索事件**（研究 · rag_search ×3）
3. 每个子任务完成后弹出**核查卡片**：`grounding 0.68 · 已支撑`

**旁白**：
> 面对复杂问题，系统会把它拆成多个独立的子任务，并行研究。
> 看右侧——三个子 Agent 同时工作，各自检索、各自查证。
> 这是本项目最核心的设计：每个子任务完成后，都会经过事实核查，
> 判断结论是否真的被检索到的原文支撑，不支撑的部分会被如实标注。
> 只有通过核查的内容才会被综合进最终答案。

**字幕**：分解 → 并行研究 → 事实核查 → 综合

---

## 镜头 5 · GPU 加速（2:30–3:00）

**画面**：右侧切到"GPU 监控"标签 → 利用率/显存/温度实时曲线跳动

**旁白（Radeon Cloud 场景）**：
> 所有推理都跑在 AMD GPU 上。切换到 GPU 监控，可以看到利用率、显存、温度实时变化。
> 在 Radeon GPU + ROCm 上，同样的模型吞吐比 CPU 提升 5 到 10 倍——
> 多 Agent 并行正是为了吃满 GPU 的并发能力：多个推理同时排队，并行调度，墙钟时间大幅缩短。

**屏幕标注**：`rocm-smi` / `bench_amd.py` 输出 tokens/s 对比表

## 录制要点
- 全程用 **OBS / Bandicam** 录屏，1080P 60fps
- 若 RC GPU 不可用：先录"单 Agent + 多 Agent"功能部分（本地 CPU 可跑），
  GPU 部分用 `benchmarks/bench_amd.py` + `rocm-smi` 截图 + Radeon Cloud 控制台录屏补充
- 剪辑加 **淡入/淡出**（0.3s），不加重叠炫光（保持"精密仪器"风格）
- 背景音乐：低音量极简电子/氛围音，避免抢戏
