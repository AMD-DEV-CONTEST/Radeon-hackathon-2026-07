# NexusAI WorldForge v0.9.1

## Save path
Extract into the existing `NexusAI/` repository root and merge folders.

## Install
From `NexusAI/apps/web`:
```bash
npm install three @react-three/fiber @react-three/drei
npm install -D @types/three
npm run dev
```

Open `http://localhost:3000/worldforge`.

## Expected
- futuristic browser-rendered 3D environment
- procedural building placeholders
- glowing knowledge core
- stars, fog, lighting
- orbit/zoom controls
- Vercel-compatible client rendering
