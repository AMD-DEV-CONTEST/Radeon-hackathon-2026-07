# 03 - 模型微调

## 概述

本项目支持对 SDXL 模型进行微调，主要方法为 **LoRA（Low-Rank Adaptation）**，可以在消费级 GPU 上以较少的显存完成模型定制。

### 支持的方法

| 方法 | 显存需求 | 训练速度 | 适用场景 |
|------|---------|---------|---------|
| **LoRA** | ~12 GB | 快 | 风格迁移、角色定制 |
| **DreamBooth** | ~20 GB | 中 | 主体驱动生成 |
| **全参微调** | ~32 GB+ | 慢 | 大规模领域适应 |

> 本项目代码实现 LoRA 微调，DreamBooth 和全参微调为框架预留接口。

## 数据集准备

### 推荐数据集结构

```
datasets/my-dataset/
├── images/
│   ├── 000000.png
│   ├── 000001.png
│   └── ...
├── train.jsonl      # 训练集元数据
├── val.jsonl        # 验证集元数据
└── dataset_config.json
```

### train.jsonl 格式

每行一个 JSON 对象，包含 `image`（图片路径）和 `text`（描述文本）：

```json
{"image": "images/000000.png", "text": "a cat wearing a hat, digital art"}
{"image": "images/000001.png", "text": "a cat wearing sunglasses, cyberpunk style"}
```

## 执行 LoRA 微调

### 基本用法

```bash
# 激活虚拟环境
source /opt/venv/bin/activate

# 执行微调
python scripts/finetune/finetune_lora.py \
    --method lora \
    --base_model stabilityai/stable-diffusion-xl-base-1.0 \
    --dataset_dir outputs/datasets/my-dataset \
    --output_dir outputs/finetune/my-lora \
    --max_train_steps 1000 \
    --learning_rate 1e-4 \
    --train_batch_size 1 \
    --gradient_accumulation_steps 4 \
    --lora_rank 64 \
    --mixed_precision fp16 \
    --validation_prompt "a photo of a cat wearing a hat" \
    --validation_steps 200
```

### 参数说明

| 参数 | 说明 | 建议值 |
|------|------|--------|
| `--method` | 微调方法 (lora/dreambooth/full) | lora |
| `--base_model` | 基础模型 ID 或路径 | stable-diffusion-xl-base-1.0 |
| `--dataset_dir` | 数据集目录 | 必填 |
| `--lora_rank` | LoRA 秩（越大能力越强但越占显存） | 64-128 |
| `--lora_alpha` | LoRA alpha 缩放系数 | 128 |
| `--learning_rate` | 学习率 | 1e-4 (LoRA) / 5e-6 (DreamBooth) |
| `--max_train_steps` | 最大训练步数 | 500-2000 |
| `--train_batch_size` | 批次大小 | 1 (12GB) / 2 (24GB) |
| `--gradient_accumulation_steps` | 梯度累积步数 | 4 (等效扩大 batch) |
| `--mixed_precision` | 混合精度 | fp16 (推荐) |
| `--seed` | 随机种子 | 42 |
| `--save_steps` | 检查点保存间隔 | 200 |
| `--validation_prompt` | 验证提示词 | 可选 |
| `--validation_steps` | 验证间隔 | 200 |

### 训练时间预估

| GPU | 显存 | 步数 | 时间 |
|-----|------|------|------|
| RX 7900 XTX (24GB) | ~14 GB | 1000 步 | ~20 分钟 |
| RX 7900 GRE (16GB) | ~12 GB | 1000 步 | ~25 分钟 |
| RX 7600 (8GB) | 不支持 | - | - |

## 使用微调后的 LoRA 推理

### 在项目 Web UI 中使用

将 LoRA 权重放到 `outputs/finetune/` 目录，系统会自动检测。

### 命令行推理

```bash
python -c "
from scripts.finetune.finetune_lora import inference_with_lora

inference_with_lora(
    lora_path='outputs/finetune/my-lora/step_final',
    prompt='a cat wearing a hat, in the style of my-lora',
    output_path='outputs/finetune/my-lora_result.png',
    steps=30,
)
"
```

### 在代码中加载

```python
from diffusers import StableDiffusionXLPipeline
import torch

pipe = StableDiffusionXLPipeline.from_pretrained(
    "stabilityai/stable-diffusion-xl-base-1.0",
    torch_dtype=torch.float16,
).to("cuda")

# 加载 LoRA
pipe.load_lora_weights("outputs/finetune/my-lora/step_final")
pipe.fuse_lora()  # 融合到原模型加速推理

# 生成
image = pipe("a cat wearing a hat, my style", num_inference_steps=30).images[0]
image.save("output.png")
```

## 微调技巧

### 数据集数量建议

| 用途 | 最少图片数 | 推荐图片数 |
|------|-----------|-----------|
| 单一风格 | 10-20 | 30-50 |
| 多风格混合 | 30-50 | 100+ |
| 人物面部 | 15-30 | 50-100 |
| 物体 | 20-40 | 50-150 |

### 提示词策略

训练时使用一致的提示词格式，例如：

```
"a photo of a [subject], [style], high quality, detailed"
```

推理时使用相同格式：

```
"a photo of a dog, in the style of my-dataset, high quality"
```

### LoRA Rank 选择

| Rank | 参数数量 | 能力 | 显存 |
|------|---------|------|------|
| 32 | ~1.5M | 基础风格 | 低 |
| 64 | ~3M | 推荐（平衡） | 中 |
| 128 | ~6M | 强风格/多概念 | 高 |
| 256 | ~12M | 精细控制 | 很高 |
