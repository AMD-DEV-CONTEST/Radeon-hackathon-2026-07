# 02 - 模型下载

## 模型清单

该项目使用以下 Hugging Face 模型：

### 核心模型（必须）

| 模型 | Hugging Face ID | 大小 | 用途 |
|------|-----------------|------|------|
| SDXL Base | `stabilityai/stable-diffusion-xl-base-1.0` | ~7 GB | 文生图/图生图 |
| SDXL VAE fp16 | `madebyollin/sdxl-vae-fp16-fix` | ~0.3 GB | VAE 显存优化 |

### 可选模型

| 模型 | Hugging Face ID | 大小 | 用途 |
|------|-----------------|------|------|
| SDXL Refiner | `stabilityai/stable-diffusion-xl-refiner-1.0` | ~6 GB | 精炼增强细节 |
| SDXL Inpaint | `diffusers/stable-diffusion-xl-1.0-inpainting-0.1` | ~7 GB | 图像修复 |
| SVD-XT | `stabilityai/stable-video-diffusion-img2vid-xt` | ~10 GB | 图生视频 |
| SD Turbo | `stabilityai/sd-turbo` | ~3 GB | 快速生成 |
| LCM LoRA | `latent-consistency/lcm-lora-sdxl` | ~0.1 GB | 快速推理加速 |

## 一键下载脚本

### 下载所有模型

```bash
cd /workspace/amd-ai-studio
bash scripts/download_models.sh
```

### 下载指定模型

```bash
# 只下载核心模型
bash scripts/download_models.sh sdxl-base sdxl-vae-fp16

# 下载全部
bash scripts/download_models.sh -a
```

### 列出可用模型

```bash
bash scripts/download_models.sh -l
```

### 指定下载源

```bash
# 从 ModelScope 下载（国内加速）
bash scripts/download_models.sh -s modelscope

# 使用 Hugging Face 镜像
export HF_ENDPOINT=https://hf-mirror.com
bash scripts/download_models.sh
```

## 手动下载

### Hugging Face

```bash
# 安装 huggingface_hub
pip install huggingface_hub

# 下载单个模型
python -c "
from huggingface_hub import snapshot_download
snapshot_download(repo_id='stabilityai/stable-diffusion-xl-base-1.0')
"
```

### ModelScope

```bash
pip install modelscope
python -c "
from modelscope.hub.snapshot_download import snapshot_download
snapshot_download('stabilityai/stable-diffusion-xl-base-1.0')
"
```

### Hugging Face 国内镜像

```bash
export HF_ENDPOINT=https://hf-mirror.com
pip install -r requirements.txt
```

## 模型缓存路径

| 源 | 默认缓存路径 |
|----|-------------|
| Hugging Face | `~/.cache/huggingface/hub/models--{org}--{name}` |
| ModelScope | `~/.cache/modelscope/hub/{org}/{name}` |
| 本项目配置 | `configs/model_paths.yaml` |

## 磁盘空间检查

```bash
# 查看模型缓存大小
du -sh ~/.cache/huggingface/hub/

# 查看磁盘可用
df -h /
```
