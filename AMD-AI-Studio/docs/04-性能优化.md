# 04 - 性能优化

## AMD GPU 优化策略

### 自动优化

系统在启动时会根据 GPU 显存自动应用优化：

```bash
# 查看优化建议
python -c "
from modules.model_optimizer import print_optimization_suggestions
print_optimization_suggestions()
"
```

### 核心优化技术

| 技术 | 说明 | 效果 |
|------|------|------|
| **FP16 推理** | 半精度浮点数 | 显存减半，速度 +50% |
| **Attention Slicing** | 分片计算注意力 | 显存降低 30-50% |
| **VAE Tiling** | 分块解码 VAE | 支持 2K+ 大图 |
| **VAE Slicing** | 分片编码 VAE | 降低编码显存 |
| **CPU Offload** | 不用的模块卸载到 CPU | 降低显存峰值 |
| **TF32 加速** | 19位精度浮点 | 速度 +20% (CDNA) |

### ROCm 环境变量优化

```bash
# ROCm 优化环境变量（已写入 /opt/venv/bin/activate）
export HSA_OVERRIDE_GFX_VERSION=11.0.0
export HIP_VISIBLE_DEVICES=0          # 指定 GPU
export ROCR_VISIBLE_DEVICES=0         # 指定 GPU
export GPU_MAX_HW_QUEUES=2            # 硬件队列
```

## 显存优化

### 不同显存的推荐配置

| 显存 | 最大分辨率 | Batch Size | CPU Offload | 可用功能 |
|------|-----------|------------|-------------|---------|
| 8 GB | 512×512 | 1 | ✅ | 文生图 |
| 12 GB | 768×768 | 1 | ✅ | 文生图 + 图生图 |
| 16 GB | 1024×1024 | 1 | 可选 | 全部功能 |
| 24 GB+ | 1536×1536+ | 2+ | ❌ | 全部功能 + 微调 |

### 手动配置优化

在 `configs/default_config.py` 中调整：

```python
# 针对 8-12 GB 显存的推荐配置
ModelConfig(
    enable_model_cpu_offload=False,
    enable_sequential_cpu_offload=True,
    enable_attention_slicing=True,
    enable_vae_tiling=True,
    use_fp16=True,
)

# 针对 24 GB+ 显存的配置
ModelConfig(
    enable_model_cpu_offload=False,
    enable_sequential_cpu_offload=False,
    enable_attention_slicing=True,
    enable_vae_tiling=False,
    use_fp16=True,
)
```

## 推理速度优化

### 使用 SD Turbo（4步生成）

```python
# 在代码中切换模型
from modules.txt2img import load_txt2img_pipeline
pipe = load_txt2img_pipeline(model_id="stabilityai/sd-turbo")

# 仅需 4 步推理
image = pipe(prompt="cat", num_inference_steps=4).images[0]
```

### 使用 LCM LoRA 加速

```python
from diffusers import StableDiffusionXLPipeline, LCMScheduler
import torch

pipe = StableDiffusionXLPipeline.from_pretrained(
    "stabilityai/stable-diffusion-xl-base-1.0",
    torch_dtype=torch.float16,
).to("cuda")

pipe.load_lora_weights("latent-consistency/lcm-lora-sdxl")
pipe.fuse_lora()
pipe.scheduler = LCMScheduler.from_config(pipe.scheduler.config)

# 仅需 4-8 步
image = pipe("cat", num_inference_steps=4, guidance_scale=1.0).images[0]
```

## 性能基准测试

### 运行基准测试

```python
from modules.txt2img import generate_txt2img
from modules.model_optimizer import run_benchmark, format_benchmark

result = run_benchmark(
    pipeline_fn=generate_txt2img,
    prompt="a cat sitting on a bench",
    num_runs=5,
    width=1024,
    height=1024,
    model_name="SDXL",
)
print(format_benchmark(result))
```

### 预期性能（RX 7900 XTX, 1024×1024）

| 模型 | 步数 | 延迟 | 吞吐量 | 显存 |
|------|------|------|--------|------|
| SDXL Base | 30 | ~3.5s | ~0.28 img/s | ~12 GB |
| SDXL Base + Refiner | 30+10 | ~5.0s | ~0.20 img/s | ~14 GB |
| SD Turbo | 4 | ~0.5s | ~2.0 img/s | ~6 GB |
| SDXL + LCM LoRA | 4 | ~1.0s | ~1.0 img/s | ~8 GB |

## 多 GPU 配置

### 指定 GPU

```bash
# 使用第 0 块 GPU
export HIP_VISIBLE_DEVICES=0
python app.py

# 使用第 1-2 块 GPU
export HIP_VISIBLE_DEVICES=1,2
python app.py
```

### 查看 GPU 状态

```bash
# 实时监控
rocm-smi

# 简化输出
rocm-smi --showmeminfo vram

# JSON 格式
rocm-smi --json
```

## ROCm 调优

### 内核选择

```bash
# 查看支持的 GFX 版本
rocminfo | grep gfx

# 覆盖内核版本
export HSA_OVERRIDE_GFX_VERSION=11.0.0
```

```bash

```

### FlashAttention

Stable Video Diffusion 使用了 FlashAttention，可通过环境变量控制：

```bash
export FLASH_ATTENTION_TRITON_AMD_ENABLE=TRUE
```
