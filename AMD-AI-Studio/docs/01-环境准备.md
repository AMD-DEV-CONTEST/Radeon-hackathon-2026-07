## 硬件要求

| CPU | x86_64, AVX2 | AMD EPYC / Intel Xeon |

| GPU | AMD Radeon RX 6000+ (8GB) | AMD Radeon PRO W7900 / RX 7900 XTX (24GB+) |
| 系统 | Ubuntu 22.04 / 24.04 | Ubuntu 24.04 LTS |

## 环境检测

使用一键检测脚本查看当前环境状态：

```bash
cd /workspace/amd-ai-studio
bash scripts/check_and_install.sh
```

该脚本会自动检测：
- CPU 型号 & 核心数
- 内存总量 & 可用
- GPU 型号 & 显存（支持 AMD ROCm / NVIDIA CUDA）
- Python 版本 & 虚拟环境
- ROCm / CUDA 版本
- PyTorch / Diffusers / Gradio 安装状态
- 缺失依赖并提示安装

## ROCm 安装（如未安装）

### Ubuntu 24.04

```bash
# 添加 ROCm 仓库
wget -q -O - https://repo.radeon.com/rocm/rocm.gpg.key | sudo apt-key add -
echo 'deb [arch=amd64] https://repo.radeon.com/rocm/apt/7.2 noble main' | sudo tee /etc/apt/sources.list.d/rocm.list
sudo apt update

# 安装 ROCm
sudo apt install rocm-hip-libraries rocm-dev

# 验证
rocm-smi --showproductname
```

> 注意：本机已安装 ROCm 7.2.3，路径为 `/opt/rocm-7.2.0`

## Python 虚拟环境

项目使用独立的 Python 虚拟环境（位于 `/opt/venv`）：

```bash
# 激活（如果使用系统默认）
source /opt/venv/bin/activate

# 或自己创建
python3 -m venv venv
source venv/bin/activate
```
