# AMD AI Studio — Local AI Creation Studio

> **AMD AI DevMaster Hackathon** Submission | Track 1: Multimodal AI Content Creation Tools

A fully-local multimodal AI creation platform built on **AMD Radeon™ GPU + ROCm™**. No internet connection required, privacy-preserving, one-click creation.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 📝 **Text-to-Image** | Generate high-quality images from text prompts (SDXL Base + Refiner two-stage) |
| 🔄 **Image-to-Image** | Upload a reference image, transform style/content via prompts, one-click style transfer |
| 🎬 **Image-to-Video** | Generate dynamic video or GIF from a single image (Stable Video Diffusion) |
| 🖌️ **Inpainting** | Paint a region + prompt to intelligently repair/replace parts of an image |
| 🖼️ **Outpainting** | Extend the canvas in any direction with AI-automated content completion |
| 🚀 **AMD GPU Optimization** | Native ROCm support, FP16 inference, automatic VRAM optimization |

## 🖥️ System Requirements

### Hardware
- **GPU**: AMD Radeon™ RX 6000/7000 series or newer (8GB+ VRAM recommended)
- **Memory**: 16GB+
- **Storage**: 30GB+ free space (for model downloads)

### Software
- **OS**: Linux (Ubuntu 22.04+ recommended)
- **ROCm**: ROCm 7.x (ROCm 7.2.3 verified in this project)
- **Python**: 3.12

## 🚀 Quick Start

### 1. Environment Check

```bash
bash scripts/check_and_install.sh
```

One-click detection of hardware, ROCm, and Python environment; automatically installs missing dependencies.

### 2. Download Models

```bash
# Default: download from ModelScope
bash scripts/download_models.sh

# Download specific models
bash scripts/download_models.sh sdxl-base sdxl-vae-fp16 sdxl-refiner

# Download from Hugging Face (auto-uses the hf-mirror.com mirror)
bash scripts/download_models.sh -s huggingface

# List all available models
bash scripts/download_models.sh -l
```

### 3. Build

```bash
bash scripts/build.sh
```

### 4. Start

```bash
# Web UI mode (default)
bash scripts/start.sh

# Or manually
python app.py
```

Open your browser and visit **http://localhost:7860**

## 🧠 Script Usage Guide

### 🔧 `scripts/check_and_install.sh` — Environment Check & Install

Detects hardware, ROCm/CUDA version, Python environment, and PyTorch/Diffusers/Gradio dependencies; automatically installs missing packages.

```bash
bash scripts/check_and_install.sh
```

Checks:
- ✅ CPU model & core count
- ✅ Total & available memory
- ✅ GPU model & VRAM (AMD ROCm / NVIDIA CUDA)
- ✅ Python version & virtual environment
- ✅ ROCm / CUDA version
- ✅ PyTorch / Diffusers / Gradio install status
- ✅ Auto-generates the `.env` config file

### 📥 `scripts/download_models.sh` — Model Download

```bash
# Download all models (default from ModelScope)
bash scripts/download_models.sh

# Download from Hugging Face mirror
bash scripts/download_models.sh -s huggingface

# Specific models
bash scripts/download_models.sh sdxl-base sdxl-vae-fp16

# List available models
bash scripts/download_models.sh -l
```

All model downloads are wrapped with the `nocache` utility, using `posix_fadvise(DONTNEED)` to prevent large downloads from flushing the system page cache and causing OOM.

### 🔨 `scripts/build.sh` — Build

```bash
bash scripts/build.sh              # All (install deps + compile kernels)
bash scripts/build.sh deps         # Install dependencies only
bash scripts/build.sh compile      # Compile ROCm-optimized kernels only
```

### 🚀 `scripts/start.sh` — Start

```bash
bash scripts/start.sh              # Web UI mode (default)
bash scripts/start.sh headless     # CLI mode (direct generation)
bash scripts/start.sh api          # API service mode
```

### 🎓 `scripts/finetune/finetune_lora.py` — LoRA Fine-tuning

```bash
# Prepare dataset
python scripts/finetune/prepare_dataset.py \
    --source local \
    --caption_strategy filename \
    --input_path /path/to/images \
    --name my-dataset

# Run LoRA training
python scripts/finetune/finetune_lora.py \
    --method lora \
    --base_model stabilityai/stable-diffusion-xl-base-1.0 \
    --dataset_dir outputs/datasets/my-dataset \
    --output_dir outputs/finetune/my-lora \
    --max_train_steps 1000 \
    --learning_rate 1e-4 \
    --lora_rank 64 \
    --mixed_precision fp16 \
    --validation_prompt "a cat wearing a hat"
```

## 🐳 Docker Deployment

### Files

| File | Purpose |
|------|---------|
| `Dockerfile` | Based on `rocm/dev-ubuntu-24.04`, preinstalls Python 3.12 + PyTorch ROCm + project dependencies |
| `docker-compose.yml` | One-click startup with GPU passthrough, volume mounts, health check |
| `.dockerignore` | Build context filter (excludes models/cache/outputs) |
| `scripts/docker_build.sh` | Image build script (with prechecks + verification) |
| `scripts/docker_start.sh` | Container start script (web / headless / api / shell modes) |

### Prerequisites

- Linux host with an AMD ROCm GPU
- Docker installed and running
- ROCm container runtime installed (`amdgpu-dkms`, `rocm-hip-libraries`)

### Build the Image

```bash
# Default build
bash scripts/docker_build.sh

# Custom tag, no cache
bash scripts/docker_build.sh -n amd-ai-studio -t v1.0 --no-cache
```

### Start the Container

```bash
# Method 1: Docker Compose (recommended)
docker compose up -d

# Method 2: Start script
bash scripts/docker_start.sh                    # Web UI mode
bash scripts/docker_start.sh -m headless        # CLI mode
bash scripts/docker_start.sh -m api             # API mode
bash scripts/docker_start.sh -m shell           # Enter shell

# Method 3: Manual docker run
docker run -d \
    --name amd-ai-studio \
    --device=/dev/kfd --device=/dev/dri \
    --group-add=video --group-add=render \
    --network host \
    -e HOST=0.0.0.0 \
    -e HSA_OVERRIDE_GFX_VERSION=11.0.0 \
    -v amd-ai-studio-hf-cache:/workspace/.cache/huggingface \
    -v amd-ai-studio-outputs:/workspace/amd-ai-studio/outputs \
    amd-ai-studio:latest
```

### Usage Inside the Container

```bash
# Enter the container
docker exec -it amd-ai-studio /bin/bash

# Download models
bash scripts/download_models.sh

# View logs
docker logs -f amd-ai-studio

# Stop the container
docker stop amd-ai-studio
```

### China Mirror Acceleration

If the ROCm base image cannot be pulled from Docker Hub:

1. Modify the base image source in the first line of `Dockerfile` to a Chinese mirror
2. Or pull and retag in advance:
```bash
docker pull registry.docker-cn.com/rocm/dev-ubuntu-24.04:latest
docker tag registry.docker-cn.com/rocm/dev-ubuntu-24.04:latest rocm/dev-ubuntu-24.04:latest
```

## ⚙️ Performance Optimization

The system automatically detects AMD GPUs and applies the following optimizations:

- **FP16 inference**: halves VRAM usage, doubles speed
- **Attention Slicing**: reduces peak VRAM
- **VAE Tiling**: supports high-resolution image generation
- **Sequential CPU Offload**: auto-enabled when VRAM is insufficient
- **TF32 acceleration**: auto-enabled on CDNA architecture
- **torch.compile**: auto-compiles the UNet on 24GB+ VRAM

Benchmark your performance with the tools in `model_optimizer.py`:

```python
from modules.model_optimizer import run_benchmark, format_benchmark
from modules.txt2img import generate_txt2img

result = run_benchmark(generate_txt2img, prompt="a cat", num_runs=5)
print(format_benchmark(result))
```
