## 4. Notes / pitfalls

- ⚠️ **vLLM version caveat**: do **NOT** set `VLLM_BATCH_INVARIANT` on build
  `0.23.1rc1.dev411.rocm723` — it regresses decode to 3.8 tok/s. Default INT4 path
  reaches 13.7 tok/s (see `docs/ROCm_Optimization.md` §4).
- All materials in **English**.
- Do not commit `.env`, API keys, or runtime data.
- 🚫 **No AI markers**: the submission (README, PR description, commit messages,
  video, PPT) must contain **no AI-generated tool attribution or watermarks**
  — e.g. no "Generated by Claude/ChatGPT", no `Co-Authored-By: Claude`,
  no AI tool logos in the demo video. Write commits with a plain message, no
  AI co-author trailer.
