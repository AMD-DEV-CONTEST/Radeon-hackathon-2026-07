# 仓库盘点 SOP 说明

## 盘点原则

- 以复盘数为最终盘点结果（复盘 vs 系统库存）
- 初盘和复盘不一致时，记录纠错并说明原因
- 无日志关联的 SKU 差异，不能自动归因，需现场实物复核
- 质量门禁失败时，不得直接上会展示管理层结论

## Agent 遵循的规则

1. 以复盘数作为盘点基准，初盘仅用于纠错记录
2. 差异计算 = 复盘数 - 系统库存数
3. 差异方向分类：盘亏、盘盈、一致
4. 盘点周期为 4/25-4/28 的四天窗口

## 质量门禁要求

- 跨交付物关键数字必须一致
- 成本单价必须锁定参考成本口径
- 外部文件禁用，只使用 inputs/ 内预定义文件
- Critical 门禁失败时不允许生成管理层报告

## 现场复核流程

无日志关联 SKU：
1. 仓库主管安排实物复核
2. 确认实物实际存放位置
3. 补充出入库记录或纠错说明
4. 返回 Agent 重新分析或手动调账
