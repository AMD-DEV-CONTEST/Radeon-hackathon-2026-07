# 库位管理制度口径

## 库位状态分类

- **启用**：正常使用的库位
- **已停用**：不再使用的库位，不应存放库存
- **维修中**：正在维修的库位，暂时不可用
- **未知**：库位主数据中未定义的状态

## Agent 库位分析规则

- 02 库存快照为「型号 × 库位」粒度
- 04 盘点表为「SKU」粒度（型号级别，不含库位维度）
- 差异不能精确归因到单个库位，仅做风险标记
- 停用/维修中库位上的差异 SKU 标记为"需库位核查"

## 注意事项

- 库位异常不等同于差异原因，仅提示可能存在库位管理问题
- 涉及异常库位的 SKU 需要现场核查，确认实物实际存放位置
- Agent 不自动修改 WMS/ERP 库位状态
- 库位管理改进建议为流程优化，需业务部门推动
