# 扫描日志治理规范

## NOISE 数据处理

- 型号以 `NOISE-` 开头的记录属于测试/干扰数据，自动排除
- NOISE 记录不计入真实操作统计
- Agent 自动统计 NOISE 数量和占比用于质量评估

## 日志完整性要求

- 出入库扫码记录必须完整，缺少记录导致差异无法追溯
- 盘点周期内的操作记录窗口为 4/25-4/28
- 操作类型包含：上架、拣货、移库、盘点

## 日志关联分类

| 分类 | 判定条件 | 处理方式 |
|------|----------|----------|
| 完全可解释 | 日志净变动量 >= 差异数量绝对值 | 可直接调账 |
| 部分可解释 | 日志净变动量 > 0 但小于差异数量 | 需补充单据 |
| 无日志关联 | 日志净变动量 = 0 | 需现场复核 |

## 改进建议

- 减少 NOISE 前缀的测试记录
- 确保每笔出入库都有对应的扫码记录
- 定期对账日志系统和实际库存变动
