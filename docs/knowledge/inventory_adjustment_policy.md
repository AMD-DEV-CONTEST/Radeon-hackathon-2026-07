# 库存调账制度口径

## 调账原则

- 调账必须基于盘点差异明细表，逐条复核后执行
- 成本口径统一使用参考成本单价，非售价
- Agent 输出调账建议，不自动执行调账操作
- 调账需经财务、仓储、审计三方复核确认

## 调账流程

1. Agent 生成差异明细表（Excel）和分析报告（Markdown）
2. 财务人员根据"可直接调账候选"分类，逐条调账
3. "需补充单据"分类：仓库补充出入库记录后，财务调账
4. "需现场复核"分类：仓库实物确认后，再判断是否调账
5. "需库位核查"分类：WMS 管理员核查库位状态后，再处理

## 调账金额口径

- 差异金额 = 差异数量 × 参考成本单价
- 盘亏减少库存和应付，盘盈增加库存和应付
- 净差异金额为负 = 盘亏为主，需要管理层关注

## 注意事项

- Agent 不生成调账分录，仅提供差异明细和分析口径
- 调账执行需在业务系统中手动操作
- 重大差异（金额 > 50,000 元）需单独审批
