# 2026-08-06 · 访谈门禁材料（Interview Gate）

> **归属**：`docs/strategy/2026-07-31-product-truth-and-next.md` 的「先验证卡点再定人格」执行步骤。
> **前置状态**：WebSerial 零安装主线（S1–S3 + U1–U4）代码侧已完成。**下一步做什么（U3 录制 / 留存 / 其它）由本门禁的结论决定。**
> **方法依据**：The Mom Test 原则（问过去行为、不问假设；不推销；找承诺信号）+ 本仓库内部共识（熟练 CLI 用户不是用户；访谈结论可修正 U3 优先级）。

---

## 0. 门禁要回答的问题（三条假设）

| # | 假设 | 现状 | 访谈怎么证伪 |
|---|------|------|-------------|
| H1 | 「装环境」是真实用户从「有硬件」到「第一次能动」的最长卡点 | 未验证（审计推理成立） | 「上次拿到新设备，你第一步做什么？卡在哪一步最久？」 |
| H2 | 零安装「第一次动 + 第一条数据」能消除该卡点，且用户愿为它花时间/钱 | WebSerial 已建好（代码侧） | Demo 后问：「现在你会怎么用它？」找**承诺信号**（要链接/要教程/要内测），不是「挺好的」 |
| H3 | 买家是「教育/教学场景」或「3–10 人小团队」（数据/版本/GPU） | 方向对、买家未定 | 筛出有真实动机的人，问他们现在的替代方案与付费史 |

**决策规则（5 人制）**：≥3 人给出「具体故事 + 承诺信号」支持 H1 → WebSerial 主线继续，**做 U3 录制**；否则 → 暂停扩功能，重定义买家（访谈 2.0）。

## 1. 招募（谁不是用户 / 谁是用户）

**筛除（否定句仍然成立）**：
- 熟练 CLI / 已装 lerobot 的人（他们自己敲命令就行）
- 只有「玩玩」动机、无场景无预算的个人

**候选池（按优先级）**：
1. 高校/职业院校机器人/机电实验室的老师与助教（采购决策或课程建设者）——教育场景
2. 3–10 人小团队：做机器人产品/数据服务/巡检方案，自己维护 1–2 条臂
3. SO-101 / SO-100 的已购用户（闲鱼、B 站教程评论区、HF Discord、LeRobot 社区）——「上次拿到设备后 48 小时发生了什么」是最真实的故事
4. Seeed 类硬件 OEM 的渠道/方案商（项目制，次优先）

**触达**：20–30 人 → 约 5–10 场（1/3 响应率）。渠道：社区贴/私信 + 学术联系人 + 已购用户群。**每天最多 2–3 场**，访谈后立即写复盘。

**开场白（私信模板）**：
> 我们在做机器人平台，想了解「拿到机械臂的人第一步实际会做什么」。不是销售，不推产品，20–30 分钟，可以录吗？就当帮我做用户调研。

## 2. 访谈脚本（45 分钟，先问题后 Demo——顺序不可反）

### 热身（5 分钟）
- 你现在在做什么？一周里花在机器人/数据上的时间大概多少？
- 你的臂/设备是哪来的？当时为什么买/申请它？

### 最近一次经历（20 分钟，核心——只挖过去，不挖假设）
- **「上次你拿到一台新机械臂/新设备，从开箱到它真正动起来，中间发生了什么？」** 让 TA 讲完整故事：卡在哪一步？等了多久？找了谁？
- 追问：那次你试过什么办法？（装软件 / 找教程 / 问群友 / 放弃了？）
- 追问：如果那次没搞定，会怎样？你后来还碰过第二次吗？
- **「现在你日常采集数据/让臂动，最烦的一件事是什么？什么时候最常发生？」**
- 追问：最近一次是什么时候？花了多长时间？你当时做了什么绕过它？
- **「为了搞定这些，你买过/装过/付过什么？」**（找付费史与替代方案：Agent 教程课？Hub 会员？请人调试？）

### 深度（10 分钟）
- 「如果明天这个烦人事消失了，你的工作/教学会有什么变化？」（H1 的重要性检验）
- 「你现在这个方案，最大的不满是什么？」（替代方案缺口）
- 「你周围还有谁也在弄这个？他们卡在哪？」（转介绍线索）

### Demo 门禁（10 分钟，H2——先问完上面再展示）
打开 `/robots/so101?mode=browser` 的 WebSerial 页面，演示：授权 → 扫舵机 → 挥手 → 3 秒录制入库。
- **「如果这是你第一次拿到 SO-101，你觉得自己会用这个吗？会卡在哪？」**（不追问「好不好」）
- **「你现在就想试试吗？要不要我把步骤写给你？」**（承诺信号 1：主动要教程）
- **「你愿意为『零安装让臂动起来 + 存第一条数据』付什么？月费/一次性/数据换额度？」**（承诺信号 2：给数字）
- 观察：TA 上手时卡在哪一步（我们自己产品的可用性证据）

### 结束（5 分钟）
- 你还有什么我没问到的？
- 可以介绍一个和你类似情况的人给我吗？
- 谢谢 + 把记录要点发给 TA 确认（不推销）。

## 4. 决策门禁（5 场后）

| 结论组合 | 动作 |
|----------|------|
| ≥3/5 支持 H1 + H2，且有付费信号 | WebSerial 主线继续 → **U3 录制优先**（数据闭环证据）+ 发布 WebSerial demo 页 |
| ≥3/5 支持 H1，H2 部分（零安装有用但不愿付费） | 主线继续，但先做「分享/留存」而非录制；重谈变现 |
| H1 被否（卡点是标定/采数/其它） | **暂停**：WebSerial 只是铺垫，转做 TA 说的真卡点（写回 roadmap，不扩功能） |
| 买家画像与 H3 明显不同 | 启动访谈 2.0（新画像），本轮不扩任何功能 |

**纪律**：访谈前不修改任何产品；访谈期间除了修崩溃 bug 不写产品代码；每场复盘进 `progress/` 或 `docs/research-log.md`。

## 5. 配套：快速问卷（可选，线下/群里补量）

5 题 30 秒，不设诱导：
1. 你是否有真实机器人硬件？(有 1 台 / 多台 / 无)
2. 上次从拿到设备到它第一次动起来，花了多久？(<1 小时 / 半天 / 1–3 天 / 一周以上 / 还没动起来)
3. 卡得最久的是哪一步？(装环境 / 接线供电 / 标定 / 没教程 / 其它)
4. 现在让机器人干活的频率？(每天 / 每周 / 偶尔 / 基本不)
5. 如果浏览器打开就能让臂动起来并保存数据，你最想先做什么？(让臂演示一个动作 / 录一段数据 / 训练一个技能 / 分享给别人看)
