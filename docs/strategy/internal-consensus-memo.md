|-----------------|-------------------|

## 共识一：跨本体控制

### 对外（统一口径）

中立软件基础设施；换机器人 = 换 Runtime；少付换机税、流程复用。

### 内部红线

1. **无轨迹级魔法**：2026 不能把 SO-101 抓取轨迹无缝搬到宇树 G1；不赌学术界未解决的万能泛化。  
2. **Runtime = 脏活**：串口、标定、低延迟控制协议，不是「一个算法搞定所有本体」。  
3. **工程北极星**：每台机型上最快训出**专用 Skill**；**同机型**版本化复用（`compatible_types` + 必要微调）。

### 对齐检查（开会必问）

- [ ] 本周是否有研发任务在追「跨本体万能 dataset」？若有，砍或降级为预研。  
- [ ] 新机型接入验收标准是否为「端到端闭环」而非「复用上一台机的 checkpoint 零微调」？

## 共识二：云端 GPU 训练（Qualia）

### 对外

P0 变现；按 GPU·时；最快 PMF；毛利 40–55%（与 SaaS 组合）。

### 内部红线

1. **算力转售无深壁垒**：租云再卖 = 二房东；HF/火山/大厂降价即挤压毛利。  
2. **云训 = 特洛伊木马**：北极星是 **Dataset Volume（用户沉淀 episode）** 与 **Workflow 周复用率**，不是 GPU 差价。  
3. **终局毛利**：团队 MLOps / Workflow **ARR**（70%+ 毛利逻辑）才是规模化利润池。

### 对齐检查

- [ ] 产品 roadmap 是否把「更多 GPU 规格」置于「Workflow 模板复用」之前？若是，调整优先级。  
- [ ] 销售是否承诺「我们靠云训赚大钱」？对外可说 P0，对内禁止当成长期商业模式唯一支柱。

## 共识三：高校 / 教育获客

### 对外

学术友好策略 → 快速占领 lab 装机 → 垄断科研级 episode 入口 → 锁定微调与团队 ARR 习惯。

### 内部红线

1. **Garbage In**：宿舍/低端 setup 的塑料杯 demo 数据，对工业/高端 VLA **价值极低**；勿幻想「白嫖高校数据训自有基础模型」。  
2. **数据主权墙**：有价值科研/企业数据受合规约束，**不能**默认上云商业化复用。  
3. **真正买到的东西**：**未来 5 年机器人工程师的肌肉记忆**——毕业生进三一、宇树、特斯拉仍用 BotverseX 工具链。

### 对齐检查

- [ ] 免费/教育档 KPI 是 **装机数 + 活跃 Workflow**，不是「上传了多少 GB 可商用数据」。  
- [ ] 法务：高校与企业数据出境/上云条款是否在 ToS 与合同模板中写清？

## 共识四：企业大客交付

### 对外

企业数据管线窄试点；工业人形/四足机队 MLOps；高客单价路径探索。

### 内部红线

1. **私有化全国部署 = 毒药**：变低毛利集成商，拖垮研发，摧毁 SaaS 倍数。  
2. **只卖标准化**：私有云 **镜像**、Local Agent + Runtime **授权**、标准 Workflow；定制开发 **转包** 伙伴 SI，我们只收工具授权/订阅。  
3. **POC 定义**：可复制的模板 + 明确成功指标；不接「驻场半年定制」除非战略领投方且书面限制范围。

### 对齐检查

- [ ] 本周商务是否出现「客户要全国私有部署 + 定制 ROS 桥」？默认 **No**，升级 Ethan 决策。  
- [ ] 合同 SOW 是否写明「不含定制集成开发」？

## 共识五：Skill Marketplace / 商店叙事

### 对外

远期上行；同机型版本化已在做；跨机型分发随 Runtime 与成功率成熟放大。

### 内部红线

1. **Seed 收入模型不含商店 GMV**；beta 为叙事与生态验证，非 ARR 主假设。  
2. **不在首聊 Deck 反复解释「我们不是 App Store」**——防御重复 = 焦虑信号（见 Manus 评审）。  
3. **A 轮前提**：云训 MRR、Workflow 复用、双 Runtime 标准、企业 POC 复购——**非**跨本体商店 GMV。
