## 当前主叙事（对外仍可用）

> BotverseX 降低真实世界机器人数据从「采集 → 训练 → 部署 → 复用」的成本，不是卖铁。

站在 LeRobot / Hugging Face 开源生态之上，做真机闭环产品层。

## 当前执行真相（对内）

> 入口（装环境）未打通前，云训 / Workflow / Marketplace 都是空转。  
> **下一步：5–10 人用户访谈 → 按卡点分布决定是否做 WebSerial。**  
> 详见 [产品真相与下一步](./2026-07-31-product-truth-and-next.md)。

## 使用原则

做产品、写代码、讲融资时优先问：

1. 是否降低「有硬件 → 第一次能动」的门槛？  
2. 是否有外部用户信号支持这个假设？  
3. 是否增强真机数据闭环，而不是多一个演示页？

若答案是否定的，不要偏航。
