1. 项目背景

AI 视频生成技术近年来取得了突破性进展，但现有工具存在两大痛点：

  • 生成后难以修改：用户对 AI 生成的视频不满意时，只能重新生成，无法精确修改某一帧的某个区域
  • 编辑工具门槛高：专业视频编辑软件学习曲线陡峭，普通用户难以进行局部重绘和帧间一致性维护

FrameForge 解决了这一问题：它将视频生成和帧级精确编辑整合到一个直观的 Web UI 中，用户可以像修图一样修视频——生成、选帧、选区、重绘、传播、导出，全流程在 AMD Radeon GPU 上本地完成。

4. 核心功能与技术实现

4.1 双后端视频生成

  • Wan2.1 Image-to-Video (14B)：文本提示词 + 参考图生成 4-6 秒视频
  • MiniMax H3 (INT8 pruned)：864×480 高质量生成，支持 instruction-guided editing
  • 采样步数可调（5-50 步），步数越多画质越精细

4.2 轮廓区域选择（替代传统画笔）

这是 FrameForge 的核心创新点。传统 inpainting 工具需要用户用画笔手动涂抹 mask，操作不精确且门槛高。FrameForge 采用：

  • Canny 边缘检测提取画面轮廓
  • 形态学闭运算连接断裂边缘，形成封闭区域
  • 连通域分析将画面分割为编号区域
  • 用户只需点击区域即可生成精确 mask，支持多选
  • 区域以半透明颜色 + 编号标签可视化标注

4.3 灵活的编辑传播

  • 仅当前帧：只修改选中的帧
  • 前向传播：改一帧，后续帧通过 RAFT 光流自动跟随
  • 双向传播：前后帧都跟随，羽化混合保持一致性
  • 传播范围可配置（1-16 帧）

4.4 完整工作流

生成 → 选帧 → 选区 → 编辑 → 传播 → 对比 → 导出，全流程在浏览器中完成。

5. 模型与算法介绍

5.1 MiniMax H3 (INT8 Pruned)

属性值
架构DiT (Diffusion Transformer)
参数量DiT ~20GB INT8 + Text Encoder ~15GB
分辨率864×480
帧对齐17k+5 (k 由步数决定)
能力Text-to-Video + Instruction-Guided Editing

5.2 SDXL Inpainting

  • 用于帧级局部重绘，在选定 mask 区域按新提示词重绘
  • 支持 ControlNet (Canny / Depth) 保持画面结构

5.3 RAFT 光流传播

  • 计算关键帧与目标帧之间的光流场
  • 将编辑后的区域 warp 到目标帧
  • 羽化混合避免边缘伪影
  • 光流一致性检测处理遮挡区域

6. AMD Radeon GPU / ROCm 适配说明

6.1 硬件环境

项目配置
GPUAMD Radeon 48GB (gfx1100)
ROCm6.3
PyTorch2.6.0+rocm6.3
VRAM 占用H3 推理峰值 ~40GB
RAM504GB DDR5

6.2 适配要点

  • PyTorch ROCm 版本：通过 pip install torch --index-url https://download.pytorch.org/whl/rocm6.3 安装
  • ComfyUI 直接兼容 ROCm，无需额外修改
  • H3 INT8 量化模型适配 48GB VRAM，完整模型可在单卡上加载
  • RAFT 光流计算使用 torchvision 内置实现，原生 ROCm 支持
  • OpenCV / FFmpeg 均使用系统默认版本，无需特殊编译

6.3 GPU 利用率

推理过程中 GPU 利用率稳定在 95-100%，VRAM 占用 99%，表明 AMD Radeon GPU 得到充分利用。
