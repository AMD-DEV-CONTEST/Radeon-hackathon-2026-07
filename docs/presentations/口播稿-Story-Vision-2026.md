## 中段要点

1. **市场**：硬件便宜、模型可租，缺口是真实数据与 Skill 分发  
2. **SpaceX 类比**：降低进入数据闭环的成本  
3. **真机证明**：SO-101、Reachy — 不是 PPT  
4. **三类机器人**  
5. **故事四页（必讲 · 有大图）**  
   - **换机税**（`robot-swap-tax.svg`）：左碎片化右兼容层，指着图讲 A 机采三个月、B 机重来。  
   - **五层兼容层**（`compatibility-layer-stack.svg`）：强调 **L2 Runtime** 高亮 ——「换机器人只动这一层」。  
   - **Skill**：不是关节角脚本，是「会抓杯子 v1.2」— 类比 App  
   - **可复用**（`data-skill-pipeline.svg`）：场景→Skill→多机；诚实一句：流程复用，轨迹按本体适配。  
   - 宇树/四足只作 **行业举例**，不说我们已在 Unitree 量产闭环。  
6. **产品截图**：Dataset / Training / Workflow / Skills — **一页一张大图**，不要三拼一页  
7. **飞轮 + 物理 AI + 三年愿景 + Skill 商店想象图**
