3DGenerateFlow

一张照片 → 一句话 → 可打印的全彩 3D / 2.5D 模型

赛道一：多模态内容创作工具开发
交付形式：Web UI
运行平台：AMD Radeon GPU + ROCm
AMD ROCm Ready

项目痛点

3D 内容创作流程复杂：多视角拍摄、建模、风格化、打印检查分散在多个工具；闭源 API 成本高、可控性差；缺少面向“照片 → 3D 打印”的端到端工具。

解决方案

3DGenerateFlow 是一个基于 Web UI 的 AI 多模态内容创作工具。用户上传一张照片、用一句话描述风格，系统即可自动编排完整生产流程，并在 AMD Radeon GPU 上本地完成所有关键推理。

🎨 图生图风格化

  • Stable Diffusion img2img，最高 1024px
  • 写实、卡通、低多边形、体素、粘土、素描等风格

🎥 多视角合成

  • Zero123 从正面图生成 front / right / back / left
  • 为 Hunyuan3D-2mv 提供一致输入

🧊 图生 3D / 2.5D 浮雕

  • Hunyuan3D-2 / 2mv 多视角 3D 生成
  • Depth Anything V2 + 高度图 → 彩色 GLB + 可打印 STL

🖨️ 打印就绪

  • 自动缩放、居中、底面贴平
  • 体积、包围盒、watertight 实时报告

技术栈

前端React + R3F
后端FastAPI + Celery
AIPyTorch + ROCm
3DHunyuan3D-2 / 2mv

AMD ROCm 适配亮点

一键脚本安装 ROCm 环境；在 AMD Radeon gfx1100（48 GB VRAM）上本地跑通 Stable Diffusion、Zero123、Depth Anything V2、Hunyuan3D-2；修复 ROCm 兼容性问题并设计纹理 fallback，无需依赖闭源 API。

应用场景

宠物/人物 3D 手办、冰箱贴/纪念币/浮雕奖牌、产品原型快速 3D 化、教育/创客空间 AI + 3D 打印教学。
