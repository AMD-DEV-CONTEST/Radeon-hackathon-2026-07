# B601 手推漂浮（重力补偿）— 当前稳定版说明

> 记录时间：2026-07-07。用户验证：3D 全关节跟手、关闭不再误唤醒电机。

## 日常怎么用

| 你想做什么 | 用哪个 | 位置 |
|-----------|--------|------|
| 主臂带动从臂 | **遥操** | 侧栏「遥操」→ 开始遥操 |
| 用手推从臂、臂变轻 | **手推漂浮** | 同页下方「手推漂浮（重力补偿）」 |
| 推到位后尽量别动（试端轻物） | **松手定住** | 手推漂浮里选第二项 |

**不能同时开遥操和手推漂浮** — 共用 CAN 总线，软件互斥（与官方 SDK 单独跑 gravity comp 一样）。

## 两种模式

### 随意手推（basic，推荐）

- 对应官方 `reBotArm_control_py` 示例 `9_gravity_compensation.py`
- 控制：重力前馈 `tau = g(q)` + 低刚度 MIT，位置指令跟随当前关节角
- 行为：抵消自重，**推到哪停哪**，不会自己弹回

### 松手定住（lock，进阶）

- BotverseX 扩展，**不是**官方示例里的默认模式
- 手还在推时：跟随意手推
- 停手且速度低于阈值：提高刚度，**尽量保持**松手那一刻的姿势
- 可试轻物（空杯）；重物或碰撞仍会下垂/偏移，不是工业级恒力持物

## 与遥操的关系

- **遥操**：LeRobot 主从映射，从臂跟主臂命令走（有自己的 MIT 增益）
- **重力补偿**：只服务从臂，不读主臂
- 官方仓库没有「遥操 + 重力补偿同时开」的流程；本项目的 `runtime_lock` 也禁止并行

## 3D 预览

1. 折叠待命 → 点 **读取从臂**（设 3D 零点）
2. 开手推漂浮 → 3D ~60Hz 跟真机（原始电机弧度，不做错误符号翻转）
3. 关手推漂浮 → runner `disable_all`，**不再**调用 recover（避免关闭时再响一遍）
