- 搜索结果必须来自实际解析/索引文件，不能从期望标签反向构造结果
- 模型、embedding、reranker 缺失必须显式记录，不得悄悄冒充启用

- 本机没有 Radeon GPU，因此 LoRA/router 和 GPU embedding 的最终 L3 验证需要现有 Radeon Cloud 服务；本地先完成真实目录 L2 检索验收

Alternatives and trade-offs:
