# B601-RS ROS2 + MoveIt2 Bridge

BotverseX 通过子进程管理 `reBotArmController_ROS2` 工作空间，暴露 `/rebotarm/*` 接口给 Web UI。

## 安装

1. 安装 ROS2 Jazzy 或 Humble（见 [Seeed ROS2 wiki](https://wiki.seeedstudio.com/cn/rebot_arm_b601_rs_ros2_integration/)）
2. 运行：

```bash
bash scripts/b601_ros2_install.sh
```

3. 重启 shell / Local Agent

## 快速启动

Web UI「高级」面板 → **Launch bringup**（等价于）：

```bash
ros2 launch rebotarm_bringup bringup.launch.py model:=rs channel:=can0
```

## API

| 端点 | 说明 |
|------|------|
| `POST /api/b601/ros2/launch` | 启动 bringup（持 ROS2 runtime 锁） |
| `POST /api/b601/ros2/stop` | 停止 bringup |
| `POST /api/b601/ros2/move_pose` | `/rebotarm/move_to_pose` action |
| `POST /api/b601/ros2/follow_joint_trajectory` | 关节轨迹 |
| `POST /api/b601/ros2/gripper/{open,close,set}` | 夹爪 |
| `POST /api/b601/ros2/gravity_comp/{start,stop}` | ROS2 service 路径重力补偿 |

## MoveIt Demo（终端）

bringup 启动后，另开终端：

```bash
ros2 launch rebotarm_moveit_demos draw_square.launch.py model:=rs
ros2 launch rebotarm_moveit_demos pick_place.launch.py model:=rs
```

## 互斥规则

ROS2 bringup 与 LeRobot 遥操、Pinocchio 直连运动学、SDK 重力补偿**不能同时**占用 CAN。若收到 409，先停止当前模式。

## 故障码

- `b601_ros2_not_installed` — 未安装工作空间
- `b601_ros2_can_conflict` — CAN 被其他 runtime 占用
- `b601_moveit_planning_failed` — MoveIt 规划失败，检查目标点与关节限位
