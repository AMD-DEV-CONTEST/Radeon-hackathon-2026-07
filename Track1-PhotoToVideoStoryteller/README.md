# Photo-to-Video Storyteller

**Track:** Track 1 — Multimodal AI
**Team:** Solo submission

## What it does
Takes an input photo and a text prompt, then generates a short animated video clip with narrated audio — turning a single image into a mini story.

## Radeon Acceleration
The video generation step is accelerated using AMD Radeon GPU resources provided for the hackathon.

## Tech Stack
- Next.js
- TypeScript
