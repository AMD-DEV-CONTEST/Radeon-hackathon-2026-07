连续音频流

每 5 秒通过 HTTP 上传一个完整 WAV；后端自动组成 30 秒技术窗口。

HTTP WAV
http://127.0.0.1:8788/api/v1/media/upload
  • 格式：单声道 PCM16 WAV，8–48 kHz；推荐 16 kHz。
  • 顺序：X-Sequence 从 0 递增；重复上传幂等。
  • 负载：WAV 二进制直接放在 Body，不使用 Base64。
  • 时间：同时提交 monotonic、clock_synced 和可选设备时间。

图片流

每张图片独立上传；连续拍摄时建议每 5 秒提交一帧。

HTTP POST
http://127.0.0.1:8788/api/v1/media/upload
  • Body：直接放 JPEG、PNG、NV12 或 YUV 原始字节。
  • 关联：音频与图片使用不同 stream_id 和独立 sequence，通过 boot_id + monotonic 对齐。
  • 顺序：X-Sequence 从 0 递增。
  • 可靠性：模型失败不会撤销已经成功保存的原始图片。

可靠上传顺序

采集完成先原子落盘；后台上传，只有 200/201 ACK 才确认并清理本地副本。

HTTP REQUESTS
1 · 本地队列

每次启动生成 boot_id，每个媒体流持久化自己的 sequence。

2 · 后台上传

提交长度、SHA-256、采集时间；超时和 5xx 按退避策略重试。

3 · 明确 ACK

accepted 与 already_accepted 都视为成功，409 冲突停止自动重试。

音频与图片上传示例

token 只放在 Authorization Header，不放在 URL、文件名或日志中。

CURL 
curl -X POST 'http://127.0.0.1:8788/api/v1/media/upload' \
  -H 'Authorization: Bearer <DEVICE_TOKEN>' \
  -H 'Content-Type: application/octet-stream' \
  -H 'X-Device-Id: demo-device-001' \
  -H 'X-Boot-Id: boot-20260727-001' \
  -H 'X-Stream-Id: microphone-main' \
  -H 'X-Sequence: 0' \
  -H 'X-Monotonic-Ms: 5000' \
  -H 'X-Clock-Synced: false' \
  -H 'X-Duration-Ms: 5000' \
  -H 'X-Filename: audio_000000000000.wav' \
  -H 'X-Media-Type: audio/wav' \
  -H 'X-Content-Length: <bytes>' \
  -H 'X-Content-Sha256: <sha256>' \
  --data-binary '@audio-0000.wav'
Glass 端建议：连续记忆的音频与图片走 HTTP；原有 WebSocket 保留给心跳、电量、唤醒和问答。模型处理在后台执行，不会阻塞下一段 WAV 的接收。

Python WAV 上传骨架

实际程序每 5 秒封装一个 PCM16 单声道 WAV，并用递增 sequence 上传。

PYTHON 
import hashlib, io, os, time, uuid, wave
import httpx

TOKEN = os.environ["DEVICE_TOKEN"]
BASE = "http://127.0.0.1:8788"
DEVICE = "demo-device-001"
BOOT = str(uuid.uuid4())
STREAM = "microphone-main"

def upload_pcm(index, pcm16, monotonic_ms):
    wav = io.BytesIO()
    with wave.open(wav, "wb") as out:
        out.setparams((1, 2, 16000, 0, "NONE", "NONE"))
        out.writeframes(pcm16)
    body = wav.getvalue()
    return httpx.post(f"{BASE}/api/v1/media/upload", content=body, headers={
        "Authorization": f"Bearer {TOKEN}", "Content-Type": "application/octet-stream",
        "X-Device-Id": DEVICE, "X-Boot-Id": BOOT, "X-Stream-Id": STREAM,
        "X-Sequence": str(index), "X-Monotonic-Ms": str(monotonic_ms),
        "X-Clock-Synced": "false", "X-Duration-Ms": "5000",
        "X-Filename": f"audio_{index:012d}.wav", "X-Media-Type": "audio/wav",
        "X-Content-Length": str(len(body)), "X-Content-Sha256": hashlib.sha256(body).hexdigest(),
    }).raise_for_status()

WebSocket 控制

Glass 只用它上报心跳、电量、唤醒和交互问答；连续媒体不再走 WebSocket。

WEBSOCKET
ws://127.0.0.1:8788/v1/device/ws

连续音画统一使用 /api/v1/media/upload；旧采集消息与旧 HTTP 上传接口已移除。
