One controlled workflow

From source files to an accountable project brief.

01 / INPUT

Upload project materials and a task CSV/XLSX into a project-scoped workspace.

→
02 / REASON

Local RAG retrieves evidence; rules + the local LLM evaluate every task.

→
03 / REVIEW

People review proposed states and confirm sensitive changes.

→
04 / DELIVER

Export cited Markdown report, risk CSV, and next-week plan.

Architecture

UI React workbench — project creation, runs, downloads
API FastAPI — controlled runner: scan → index → retrieve → evaluate → draft
RAG Safe import · FAISS + BM25 hybrid retrieval · project-scoped isolation
LLM llama.cpp (HIP/ROCm) — chat :8000 + embeddings :8080
OUT Report · risk CSV · next-week plan · structured JSON

Why it matters

  • 1 Evidence-backed status instead of subjective standups.
  • 2 Private & local — no data leaves the controlled workspace.
  • 3 Human-in-the-loop confirmation for any sensitive write.
  • 4 Full audit trail: original task lists are never modified.

Optimised for AMD Radeon

Qwen3.6-35B runs locally through llama.cpp HIP on ROCm with full GPU offload (--n-gpu-layers 999). Project data stays private while the Radeon GPU powers both chat reasoning and retrieval embeddings.
