# Project showcase

This folder holds the Track 2 supplementary materials (demo video, poster, and
landing page) for **ProjectPack Office Agent — Team PLASMA**.

## Contents

- **Demo video (3–5 min, on AMD Radeon GPU):**
  <https://www.bilibili.com/video/BV14BMB6gEKu/>
- **Poster (PDF):** `PLASMA_ProjectPack_Poster.pdf` — competition poster
  emphasising the creative scenarios, architecture, and AMD Radeon / ROCm
  value of the tool.
- **Landing page:** open `index.html` in a modern browser to view the static
  ProjectPack showcase page.

The landing page is intentionally independent of the authenticated office
workbench. It is suitable for a competition landing page, a poster-style
screenshot, or a demo-video opening shot.
