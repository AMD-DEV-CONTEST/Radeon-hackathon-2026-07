## 📌 Overview

**InterviewIQ AI** is an AI-powered interview preparation platform designed to help students and job seekers practice technical and HR interviews in a realistic environment.

Unlike traditional mock interview platforms, InterviewIQ AI combines **AI voice interviews, resume-based questioning, coding assessments, DevOps terminal simulations, webcam confidence analysis, and personalized learning analytics** into a single platform.

The goal is to improve interview confidence, communication skills, and technical problem-solving before facing real interviews.

---

# ✨ Key Features

### 🎤 AI Voice Interview
- AI asks interview questions using voice.
- Candidate responds through microphone.
- Speech-to-text captures answers in real time.

---

### 📄 Resume-Based Interview

- Upload or paste your resume.
- AI extracts projects and technologies.
- Generates personalized interview questions.

---

### 💻 Coding Assessment

- In-browser coding environment.
- JavaScript & Python support.
- Basic logic and complexity evaluation.

---

### 🐳 DevOps Terminal Simulator

Interactive Linux terminal for practicing DevOps troubleshooting.

Practice commands like:

```bash
kubectl get pods

kubectl logs

docker ps

fix-pod
```

Simulates Kubernetes troubleshooting scenarios such as:

- CrashLoopBackOff
- Pod failures
- Container debugging

---

### 👁️ Confidence Analysis

Provides interview confidence metrics including:

- Eye Contact
- Facial Confidence
- Speaking Pace
- Communication Analysis

---

### 📊 AI Performance Dashboard

After each interview, users receive:

- Overall Interview Score
- Technical Score
- Communication Score
- Strengths
- Weak Areas
- Learning Recommendations

---

### 🛣️ Personalized Learning Roadmap

Generates a step-by-step roadmap based on candidate performance.
