## 二、从你的电脑访问（SSH 隧道，推荐）
1. 将服务器的 SSH 私钥拷到本地电脑（私钥路径以服务器管理员提供的为准）
2. 在本地电脑执行（可同时转发两个端口）：
   ```bash
   ssh -i <your_private_key> -N -L 7860:127.0.0.1:7860 -L 8188:127.0.0.1:8188 root@<SERVER_PUBLIC_IP>
   ```
   （保持该窗口不关闭，或加 `-f` 后台运行）
3. 本地浏览器打开 `http://localhost:7860` 使用 WebUI，`http://localhost:8188` 使用 ComfyUI

- 若 ssh 连接超时：说明平台外层防火墙封禁了 22 端口，SSH 方案不可用，需改用 Cloudflare Tunnel

## 三、服务管理命令（在服务器上）
```bash
# 启动/重启 WebUI
bash /persistent/start_webui.sh
# 停止 WebUI（在服务器上执行）
pkill -9 -f '[p]ython webui.py'
# 查 WebUI 日志
tail -f /tmp/webui_run.log

# 启动/重启 ComfyUI
bash /persistent/start_comfyui.sh
# 查 ComfyUI 日志
tail -f /tmp/comfyui_run.log

# sshd
bash /persistent/start_sshd.sh
```
