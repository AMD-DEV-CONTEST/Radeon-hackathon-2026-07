# 2026 AMD AI DevMaster 黑客松赛事说明

# 概述

加入由 **AMD**（Advanced Micro Devices, Inc\.）主办的 AMD AI DevMaster 黑客松。本次黑客松聚焦前沿 AI 应用创意和高性能 AMD GPU 技术。选择你心仪的赛道！探索 AI 应用的无限可能，借助完全开源的 AMD ROCm 软件栈释放 AMD GPU 的全部计算潜力。让强大的 AMD Radeon GPU 成为你实现创意想法、运行模型的终极引擎！

本次黑客松包含三个赛道，涵盖 AI 创新应用开发的核心方向。无论你擅长将创意转化为实际应用，还是精于底层技术优化，这里都能找到属于你的理想舞台！

## 赛道一：多模态内容创作工具开发

基于 AMD Radeon GPU 的计算能力和 ROCm 开源软件栈，开发轻量级、高性能的 AI 多模态内容创作工具。参赛者可自行定义创作风格和应用场景，并构建借助 GPU 计算的有趣应用。例如，对图片、短视频等素材应用智能风格迁移和二次创作，将真实场景、日常拍摄和商业内容转化为具有动漫、赛博朋克、复古质感、极简艺术等自定义风格的视听作品。

本赛道聚焦轻量化部署、推理加速、风格定制、画质优化四大核心方向，旨在充分挖掘 AMD GPU 的多模态计算优势，提供实用、高效、个性化的 AI 内容生成方案，适用于个人创作、新媒体运营、商业视觉设计、短视频制作等多种行业场景。

## 赛道二：私有 AI Agent 开发与本地部署

采用开源 AI Agent 开发套件，在 AMD Radeon GPU 和 ROCm 平台上完成全流程本地私有化部署，打造高度适配、可定制的专用 AI Agent。参赛者可自由定义应用场景，打破通用 AI 工具的功能局限，创造出具备场景化服务能力的智能体。

可用场景包括个人智能助手、办公自动化助手、行业专用服务 Agent、日常生活管理工具等。本赛道重点考察参赛者利用 AMD GPU 算力优化 Agent 推理速度、提升本地部署稳定性以及实现自定义迭代功能的能力，目标在于打造轻量化、高可用、私密化的 AI 智能服务终端。

## 赛道三：具身智能挑战——基于 AMD Radeon GPU 和 ROCm 的机器人仿真与应用设计

本赛道结合物理仿真技术和具身智能算法，借助 AMD Radeon GPU 的计算能力与 ROCm 开源软件栈，开发面向机器人交互场景的仿真系统与自主控制方案。参赛者可选择机械臂、人形机器人、轮式机器人、四足机器人等机器人形态，完成运动规划、动态平衡、物体交互及自主操作等 Physical AI 任务。

支持的应用场景包括智能机械臂精准抓取与放置、移动机器人自主导航与避障、四足机器人动态步态控制、多刚体物理交互控制等任务，不做限制。所有环境执行、模型训练与实时推理必须在单张 AMD Radeon GPU 上完成。参赛者需优化物理仿真步进、动力学求解、AI 策略推理等全流程，提升仿真性能、控制响应速度与任务稳定性。

本赛道聚焦物理仿真设计、轻量化 Physical AI 模型与算法开发、GPU 计算调度、端到端延迟优化四大核心领域，旨在充分探索 AMD Radeon GPU 在并行计算、实时仿真和 AI 推理方面的能力，同时交付轻量化、低延迟、可部署的机器人 Physical AI 解决方案。成果可推动物理仿真、机器人控制和嵌入式智能体在个人研发、教学培训、小型智能设备等场景中的应用。

# 规则

## 赛道一：多模态内容创作工具开发

### 1\. 任务描述

借助 AMD Radeon GPU 的计算能力和 ROCm 开源软件栈，开发一款实用、轻量级、高性能的 AI 多模态内容创作工具。你的作品需至少支持以下一项核心创作任务：

- 图像风格迁移

- 图像生成 / 图像编辑

- 文生图 / 图生图

- 短视频片段风格化处理

- 图像与视频画质增强

- 视听内容的二次创作与批量处理

- 文生视频

- 图生视频

- 其他

参赛者可自行定义创作主题和应用场景，如新媒体内容制作、个人创作、商业视觉设计、短视频制作等。

### 2\. 指定技术栈

为确保比赛标准统一，规定技术栈如下：

（1）硬件与平台要求

- 必须运行在 AMD Radeon GPU 上

- 必须采用 ROCm 软件栈

- 最终作品需可在指定的 AMD 环境中部署和演示

（2）推荐框架

- PyTorch \+ ROCm

- ComfyUI / Diffusers / Transformers（确保兼容 AMD Radeon GPU）

- 辅助库：OpenCV / FFmpeg / Pillow 等

- 其他符合条件的框架

（3）模型要求

- 可采用开源模型进行工程化修改和优化

- 允许使用 LoRA、ControlNet、轻量化推理模型和蒸馏模型

- 不允许核心功能仅依赖闭源在线 API

- 至少一个关键推理过程必须在 AMD Radeon GPU 上本地运行

（4）交付形式

- 作品需以至少一种以下可演示形式呈现：

- Web UI

- 桌面应用

- 插件工具（如创作工作流插件）

- CLI 工具 \+ 演示工作流

- 其他有效形式

### 3\. 评审标准（总分：100 分）

（1）功能完整性与应用价值（80 分）

- 完整的输入\-处理\-输出工作流：40 分

- 创作场景的创新性和趣味性：20 分

- 实际应用与社会价值：20 分

（2）在 AMD Radeon GPU 上的运行表现（20 分）

- 工具输出清晰、稳定且多样化：20 分

### 4\. 提交要求

（1）项目简介文档（PDF）

- 项目背景

- 目标用户与应用场景

- 系统架构

- 模型与算法介绍

- AMD Radeon GPU / ROCm 适配说明

（2）项目源代码

- 完整源代码仓库

- README 文件，包含环境配置、启动指南和依赖列表

（3）演示视频

- 建议时长：3–5 分钟

- 展示实际操作流程

- 在 AMD Radeon GPU 上的实际执行表现，从命令行/GUI 到最终结果（输出清晰度、稳定性和多样性）

（4）补充材料（选择一项）

## 赛道三：Physical AI 挑战——基于 AMD Radeon GPU 和 ROCm 的机器人仿真与应用设计

### 1\. 任务描述

基于 AMD Radeon GPU 和 ROCm 平台，设计并开发一套完整的机器人应用流程。机器人形态不作限制，可包括但不限于机械臂、人形机器人、四足机器人、移动机器人或其他机器人系统。

所提交方案应展示以下一项或多项能力：

- 仿真能力：能够构建并利用基于物理的仿真环境完成机器人任务。

- 机器人学习能力：能够使用基于学习的方法训练智能机器人策略。

- 泛化与鲁棒性：能够在不同环境、干扰或未见场景下保持稳定表现。

- 闭环控制：能够执行推理驱动的感知\-决策\-控制闭环，实现机器人操作。

- GPU 优化能力：能够有效利用 AMD Radeon GPU 和 ROCm 软件栈进行加速与优化。

- 多模态感知融合能力：能够融合来自多种传感模态的信息，增强感知并支持机器人决策。

应用领域可包括但不限于：

- 操作：使用机械臂完成可泛化的机器人抓取与操作任务。

- 全身操控：人形机器人完成协调的全身任务。

- 移动导航：移动机器人自主导航与避障。

- 腿足运动与操作：四足机器人的动态运动与任务执行。

- 复杂物理交互：涉及柔性物体、可变形物体或其他挑战性物理现象的交互。

- 多智能体机器人：多机器人之间的协同感知、规划与执行。

- 自动驾驶：面向多样化交通场景的物理驱动仿真、闭环车辆控制与鲁棒策略泛化。

### 2\. 指定技术栈

（1）平台要求

- 方案必须基于 AMD Radeon GPU 和 ROCm 软件栈。

（2）推荐开发框架

- 方案应基于开源机器人仿真框架构建，如 Genesis、MuJoCo 或其他等效替代方案。

- 应使用开源模型训练框架。

（3）模型要求

- 参赛者须使用与 Embodied AI、Physical AI 或相关研究领域相关的开源模型。

（4）数据要求

- 可使用公开数据集和/或自建数据集。

- 参赛者须确保所有数据集符合适用的法律、许可和伦理要求。

### 3\. 评审标准（总分：100 分）

（1）机器人能力表现（30 分）

- 基于机器人系统任务执行效果和整体任务完成表现进行评估。

（2）AMD Radeon GPU 与 ROCm 采用度（20 分）

- 流程的关键阶段，包括训练和/或推理，应在 AMD Radeon GPU 上执行。

（3）创新性（20 分）

- 基于所提交方案与应用设计的新颖性和原创性进行评估。

（4）应用价值（20 分）

- 基于所提交应用与现实行业需求的关联度和实际影响力进行评估。

- 现实价值越高的应用将获得更高分数。

（5）上游开源社区贡献（10 分）

- 比赛期间对上游开源项目（尤其是改进 AMD 平台支持）所做的贡献将被评估并给予奖励。

技术报告应包括但不限于以下内容：
