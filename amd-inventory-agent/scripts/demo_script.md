# InventoryDoc Agent — 3 分钟 Demo 脚本

## 时间线

### 0:00-0:20 — 痛点（20 秒）

**画面**：屏幕录制一个 Excel 表格，密密麻麻的数据

**台词**：
> 每次盘点结束，仓储经理都要面对这样的 Excel——10 份数据、528 个 SKU、几千行记录。
> 手动分析需要 2-3 天，还经常算错——基准选错、成本用售价、数字前后不一致。
> 管理层开会时，差异原因说不清，追责无从下手。

### 0:20-0:40 — 方案（20 秒）

**画面**：切换到 InventoryDoc Agent 的 Web 界面

**台词**：
> 我们做了 InventoryDoc Agent——一个完全本地部署的 AI Agent。
> 上传 10 份盘点数据，10 分钟自动生成可直接上会的调账材料。
> 所有数据本地处理，零云端依赖。

### 0:40-1:30 — 演示 Part 1：数据加载与噪音识别（50 秒）

**画面**：Web UI 操作录屏

**台词**：
> 我们用科勒供应链的真实盘点数据来演示。

**操作**：
1. 在输入框输入 `data/input`，点击"开始分析"
2. 展示 Step 1 结果：10 个文件全部加载成功
3. 展示 Step 2 结果：
   > Agent 自动识别出 68 条 NOISE 干扰数据——这些是 RF 扫码的环境噪声，混在真实操作里。
   > 还排除了 2 份不适用文件：月报是品类汇总粒度，历史库存含 200 多条异常记录。
   > 人工做这一步需要逐行检查，Agent 3 秒完成。

### 1:30-2:10 — 演示 Part 2：核心分析（40 秒）

**画面**：展示 Step 5-7 的结果表格

**台词**：
> 基准选择：Agent 自动对比两个库存快照的编码体系，选定了型号编码的那个——与盘点表一致。
>
> 差异计算：系统库存 21,144 件，复盘 20,173 件，净差异 -971 件，差异率 4.6%。
> 净差异金额 -989,900.97 元——近百万的库存差异，必须精准定位。
>
> 关键创新：日志关联三分类。Agent 按净变动量比对，把 159 个差异 SKU 分成三类：
> - 14 个完全可解释——有对应的出入库操作
> - 21 个部分可解释——有操作但量不足
> - **124 个无日志关联——这些才是需要现场实物复核的重点**

### 2:10-2:40 — 创新点（30 秒）

**画面**：展示质量校验结果 7/7 通过

**台词**：
> 我们的两个核心创新：
>
> 第一，**噪音自动识别**。市面上没有 Agent 能自动识别 RF 扫码噪音、异常数据、不适用文件。我们做到了。
>
> 第二，**7 条质量校验**。内置企业级规则——基准必须三维论证、成本必须用单价而非售价、噪音文件必须排除。任何一条不通过，Agent 会标记警告。
>
> 这让 AI 输出不再是"黑箱"，而是可审计、可追溯的。

### 2:40-3:00 — 价值与收尾（20 秒）

**画面**：展示生成的 Excel 和分析报告

**台词**：
> 最终输出：一份 Excel 差异明细表（4 sheets）和一份分析报告（4 章），管理层直接上会使用。
>
> InventoryDoc Agent——让库存盘点差异分析从 2-3 天缩短到 10 分钟。
> 基于 AMD Radeon GPU + ROCm 本地部署，数据不出设备。
>
> 谢谢。

## 录制注意事项

1. **Demo 数据**：使用 `data/input/` 中的真实科勒数据
2. **录屏工具**：OBS（免费）或 Loom
3. **分辨率**：1080p，字体放大到 120%
4. **语速**：中等偏快，3 分钟内讲完
5. **备份录制**：如果 demo 可能失败，提前录制一份备份
6. **字幕**：建议加中文字幕，方便评委理解

## 预期效果

- 评委 90 秒内能理解：痛点 → 方案 → 创新点
- 演示数据真实（科勒供应链），不是 mock 数据
- 核心指标与地面真值一致，经得起验证
