## 🚀 Project Summary

**DataGuard AI** is a local-first, autonomous ReAct agent engineered to audit tabular datasets and ensure secure enterprise data governance.

* **Autonomous ReAct Planning:** Dynamically coordinates across 6 deterministic auditing tools (missingness, duplicates, target leakage, class imbalance, outliers, and high-cardinality identifiers).
* **Dual-Gate Security Architecture:** Combines an AST structural allowlist with closed-loop semantic re-verification to guarantee safe, verified data auto-remediation.
* **AMD ROCm Hardware Portability:** Seamlessly dispatches local inference via Ollama to AMD Radeon hardware with zero application-layer modifications.
