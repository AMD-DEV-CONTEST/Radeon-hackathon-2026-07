# AgentOS

## Track
Track 2 – Development & Local Deployment of Private AI Agents

## Project Overview
AgentOS is an AI-powered private assistant that combines Retrieval-Augmented Generation (RAG), OCR, conversation memory, and web search into a single application. Users can upload PDF documents and images, ask questions about their content, and receive intelligent responses using locally deployed AI models.

## Features
- Document Question Answering (RAG)
- OCR-based Image Text Extraction
- Conversation Memory
- Hybrid Web Search
- Multi-LLM Support
- Streamlit Web Interface

## Tech Stack
- Python
- Streamlit
- LangChain
- ChromaDB
- Sentence Transformers
- EasyOCR
- Groq API
- AMD Radeon Cloud

## Deployment
The application was validated and demonstrated on AMD Radeon Cloud.
