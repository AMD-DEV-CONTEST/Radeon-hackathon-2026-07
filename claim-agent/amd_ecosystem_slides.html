Deepest Optimization · Hand-Written Kernel Support

AITER → RDNA3 (gfx1100):
Vendor-Gated Kernel Port, First in This Track

AMD's AITER library upstream-lists this card — W7900 (gfx1100, RDNA3) — as Experimental. But vLLM's integration layer never exposed AITER here: it only enabled CDNA3 data-center chips and (later) RDNA4. RDNA3 fell in the gap — every AITER op silently fell back to emulation. We closed that gap in 4 source changes and ran AITER in vLLM on consumer RDNA3 for the first time. Upstream vLLM still doesn't ship this.

  1. vllm/_aiter_ops.py — arch gate: on_mi3xx() or on_gfx1100()
  2. aiter_meta/csrc/cpp_itfs/utils.py — arch allow-list + gfx1100
  3. aiter/ops/triton/configs/gemm/gfx1100-GEMM-A8W8.json — new M-band tuning config
  4. vllm/_aiter_ops.py — route gfx1100 to Triton WMMA gemm_a8w8 (CK XDL kernels can't compile on RDNA3)
