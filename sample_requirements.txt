Hackathon Submission Requirements

The project must be submitted as a pull request to the official repository. The pull request title must follow the format: Track 2, Team Name or Participant Name, Application Name.

All submission materials must be written in English. Required deliverables are a project specification PDF, complete source code, an English README, and a playable three-to-five-minute demo video.

The application must demonstrate local inference on an AMD Radeon GPU. The optimization section should describe the ROCm software stack and include measured inference performance. Unsupported performance claims must not be presented as measured results.

The final review should confirm that the pull request remains open, every required file is present, and the demo video link is accessible.
