## What is LaunchKart AI?

LaunchKart AI 2.0 is a **production-grade multi-agent AI platform** that converts a single product image into a complete marketplace-ready product launch. Upload a photo → get listings, SEO, pricing, marketing campaigns, and marketplace exports — all generated by a team of 15 AI agents running locally on your **AMD Radeon GPU**.

## 🚀 Quick Start

### Prerequisites

- Python 3.11+
- Node.js 20+
- Docker & Docker Compose
- [Ollama](https://ollama.ai) with ROCm support (for AMD GPUs)

### 1. Clone & Configure

```bash
git clone https://github.com/your-org/launchkart-ai.git
cd launchkart-ai
cp .env.example .env
```

### 2. Start Infrastructure

```bash
docker compose -f docker/docker-compose.yml up -d postgres redis chromadb
```

### 3. Start Backend

```bash
cd backend
python -m venv .venv
.venv/Scripts/activate  # Windows
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 4. Start Frontend

```bash
cd frontend
npm install
npm run dev
```

### 5. Open Dashboard

Navigate to [http://localhost:3000](http://localhost:3000)

## 🖥️ AMD Radeon GPU Integration & ROCm Setup

LaunchKart AI 2.0 is highly optimized for AMD Radeon GPUs, utilizing ROCm for accelerated local LLM inference via Ollama. This provides the massive parallel processing power needed to run our 15-agent pipeline efficiently.

### 1. ROCm & Ollama Setup
To leverage your AMD Radeon GPU for this project:
1. **Install AMD Drivers**: Ensure you have the latest AMD Software (PRO or Adrenalin Edition) installed for your Radeon GPU.
2. **Install Ollama**: Download and install Ollama for Windows/Linux from [ollama.com](https://ollama.com/). Ollama natively includes ROCm support for compatible AMD GPUs.
3. **Pull the Model**: Run `ollama run llama3` (or your preferred model). Ollama will automatically detect the Radeon GPU and offload layers to VRAM.

### 2. How the Project Utilizes AMD GPUs
- **High-Throughput Local Inference:** All 15 AI agents operate entirely locally using models served by Ollama on the ROCm backend, ensuring privacy and zero API costs.
- **Parallel Agent Execution:** Our LangGraph architecture triggers multiple agents simultaneously (e.g., SEO, Pricing, and Marketing). The AMD GPU handles concurrent LLM requests, drastically reducing overall generation time.
- **Real-Time Telemetry:** The frontend dashboard displays live AMD GPU metrics (VRAM usage, Tokens/Sec, Temperature, Power Draw) so users can monitor hardware performance in real-time.
- **CPU vs. GPU Benchmarking:** Built-in tools allow users to benchmark the pipeline, highlighting the massive performance delta between CPU execution and AMD ROCm acceleration.
