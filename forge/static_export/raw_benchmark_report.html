1. Formulated Hypotheses & Experimental Controls

Hypothesis & Experimental Design

H1: Hardware Acceleration & Scale Transfer

Deploying flagship parameter models (>70B / 236B) on 192GB VRAM hardware (AMD Instinct MI300X via vLLM) yields a >50x reduction in mean inference latency compared to local sub-bit CPU/GPU execution without degrading schema recall.

H2: Quantization Formatting Degradation

Sub-8-bit quantizations (Q4_K_M GGUF) introduce syntactic formatting artifacts (e.g., Markdown codeblock wrappers) that choke raw JSON parsers. A deterministic normalizer can resolve formatting errors without altering core model reasoning.

4. Analytical Discussion & Scientific Interpretation

Interpretation & Analysis

Latency vs. Accuracy Trade-Off Analysis

The empirical data confirms H1: Executing 35B–236B models on the AMD Instinct MI300X (vLLM) reduced mean inference latency from 74,241 ms (local QwQ-32B) to 937–982 ms, representing a 75x to 80x execution speedup.

Quantization Degradation & Normalizer Recovery

The empirical data confirms H2: Ornith-35B-Q4_K_M on local hardware received a raw zero-shot score of 0.0/100 due to outputting Markdown syntax wrappers (```json). When processed through the deterministic normalizer (normalizer.rs), the extracted JSON scored 93.2/100, matching the unquantized BF16 MI300X run.

Confounders and Limitations

  • Network & JIT Latency: Initial vLLM model loads include ROCm kernel JIT compilation overhead.
  • Gated Model Exclusions: Certain HuggingFace repositories required authentication tokens and were excluded from automated sweeps to prevent incomplete measurement reporting.
