# radeon-fix demo video

This directory contains everything needed to reproduce the English demo video
for `radeon-fix`. The video is a ~3.5-minute replay of a real repair session
recorded on the AMD Radeon instance: the terminal shows the agent working, and
the right-hand panel shows the code it generates as it is written.

## Demo task

The task is the `examples/demo_project` fixture ("pycalc"): three bugs across
two modules (`mode` tie-breaking, `normalize` min-max scaling, and
`summary_text` truncation), covered by seven failing tests. The agent fixes
all three and the verifier accepts; applying the frozen patch makes all seven
tests pass.

## Assets

- `demo-assets/demo-session.txt` + `demo-assets/demo.timing` — the real
  terminal session recorded on the AMD instance with `script --timing`.
- `demo-assets/trajectory.json` — full agent trajectory; its action envelopes
  drive the generated-code panel.
- `demo-assets/out/` — artifacts from that run: `patch.diff`, `report.md`,
  `run.json`, `gpu.json`.
- `replay.template.html` — the 1920×1080 replay page (terminal + generated-code
  panel + English captions).
- `replay.html` — generated by the recorder (session and actions embedded).
- `record_video.js` — Playwright recorder: renders `replay.html`, records a
  1920×1080 webm, converts it to `radeon-fix-demo.mp4`, and saves mid-run
  screenshots under `screenshots/`.
- `screenshots/` — intro, code-generation, midway, late, and final stills.

## Re-record

```bash
cd demo
node record_video.js
```

The script uses the Playwright package from the Codex runtime and a full
ffmpeg. Override paths with `SESSION_FILE`, `TIMING_FILE`, `TRAJECTORY_FILE`,
`FFMPEG`, and `CHROMIUM_PATH` environment variables if needed.

## Record a new session on the AMD instance

```bash
export PATH=/root/radeon-code-agent-venv/bin:$PATH
cd /root/radeon-fix-demo2
script -q --timing=demo.timing -c "env TRACK2_BASE_URL=http://127.0.0.1:8000/v1 \
  TRACK2_API_KEY=local-vllm TRACK2_MODEL=Qwen3-14B-BF16 \
  /root/radeon-code-agent-venv/bin/python /workspace/radeon-code-agent/radeon_fix.py \
  --repo /root/radeon-fix-demo2/demo_project \
  --issue \"pycalc has three bugs: 1) mode breaks ties by returning the first \
  encountered value instead of the smaller value; 2) normalize scales by the \
  maximum instead of the min-max range, crashes when the maximum is 0, and \
  does not handle all-equal inputs; 3) report.summary_text only prints the \
  first five normalized values instead of all of them. Fix all three so every \
  test in tests/ passes.\" \
  --output-dir /root/radeon-fix-demo2/out \
  --max-turns 16 --max-tool-calls 40 --max-wall-time 900" demo-session.txt
```

Copy `demo-session.txt`, `demo.timing`, and `trajectory.json` back into
`demo/demo-assets/` and re-run `node record_video.js`.
