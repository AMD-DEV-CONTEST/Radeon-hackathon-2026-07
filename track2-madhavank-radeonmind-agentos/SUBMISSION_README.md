# RadeonMind-AgentOS -- Track 2 Submission

**Author:** Madhavan K
**Track:** Track 2: Development & Local Deployment of Private AI Agents
**Application Name:** RadeonMind-AgentOS (AMD Hackathon)

RadeonMind-AgentOS is a state-of-the-art, fully local, private multi-agent execution framework designed from the ground up for AMD Radeon GPUs. Featuring ReAct task DAG planning, sliding window context compression, a FAISS vector database with recency-decay long-term memory, and an autonomous self-correcting debugger sandbox, it delivers high-performance agentic workflows entirely offline.
