RadeonPilot

Multi-Agent ROCm Inference Operations on a Single AMD Radeon GPU — Private, Local, Evidence-Bound
AMD Hackathon 2026 · Track 2

The Scenario

RadeonPilot turns one Radeon GPU into a self-inspecting inference server. A fleet of Pi agents performs the full ops loop: diagnose the ROCm stack, deploy the model endpoint, benchmark it, locate bottlenecks, and propose validated optimizations. Every agent generation runs on the Radeon itself — private by construction, aligned with AMD's ROCm.AI agent-workflow direction.

Agent Fleet (Pi Agent Harness 0.83.0)

  • Privacy: loopback-only, disabled Pi tools, redacted audit
  • Radeon core inference: attested via amd-smi device occupancy
