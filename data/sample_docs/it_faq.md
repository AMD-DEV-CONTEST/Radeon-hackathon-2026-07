# 内部 IT FAQ（示例私有知识库）

## Q1：如何重置 VPN 密码？
打开内部门户 → Security → Reset VPN Password。需要完成 MFA。

## Q2：涉密文档可以使用哪些 AI 工具？
仅允许 **PrivateLocalAgent** 及公司批准的本地模型。禁止把机密内容粘贴到公网聊天机器人。

## Q3：如何申请新的软件许可证？
在 ServiceDesk 提单工单并填写成本中心 ID。标准审批 SLA 为 2 个工作日。

## Q4：项目设计文档存放在哪里？
存放在私有知识库目录 `Projects/Design`，按角色授权访问。

## Q5：GPU 推理环境如何要求？
Track 2 开发使用 AMD Radeon GPU + ROCm。私有负载优先本地推理。

## IT FAQ 列表摘要
本知识库包含：VPN 重置、AI 工具合规、软件许可证申请、设计文档位置、AMD ROCm GPU 推理要求。
