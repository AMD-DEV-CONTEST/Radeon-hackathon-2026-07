# TalentTwin AI – Digital Career Twin and Placement Readiness Platform

## Track
**Track 2 – Development & Local Deployment of Private AI Agents**

## Participant
**Varsha**

## Project Overview

TalentTwin AI is an AI-powered career intelligence platform that creates a digital twin of a student's professional profile. The platform analyzes resumes, identifies skill gaps, evaluates placement readiness, predicts suitable career paths, and generates personalized learning roadmaps to improve employability and career success.

## Problem Statement

Many students struggle with:

- Creating ATS-friendly resumes
- Identifying missing technical and soft skills
- Preparing for interviews
- Choosing suitable career paths
- Understanding their placement readiness

TalentTwin AI addresses these challenges by providing AI-driven insights and personalized career recommendations.

## Features

- Resume Upload & Analysis
- ATS Score Calculation
- Skill Gap Detection
- Career Path Prediction
- Personalized Learning Roadmap
- AI-Based Career Recommendations
- TalentTwin Score Dashboard

## Installation

Clone the repository:

```bash
git clone https://github.com/varsha774/TalentTwin-AI.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
