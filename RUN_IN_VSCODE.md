# Run in VS Code

This project can open in VS Code, but SDXL image generation is recommended on Google Colab with a T4 GPU.

```powershell
cd C:\Users\nikha\Documents\Codex\image_only_secure_project
pip install -r requirements_vscode.txt
python app.py
```

Open:

```text
http://127.0.0.1:7860
```

If CUDA is not available, use Google Colab for image generation.
