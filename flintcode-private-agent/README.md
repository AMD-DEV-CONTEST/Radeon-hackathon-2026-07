# FlintCode Private Agent

## 1. Application Scenarios
FlintCode is an enterprise-grade, **private deployment (Local-first)** coding agent designed for complex microservices and domain-driven design (DDD). By running entirely on local AMD Radeon GPUs, it completely eliminates data leakage risks associated with uploading proprietary corporate IP to cloud-based LLMs.
