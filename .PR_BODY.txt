## Private RAG Agent — Track 2 Submission

A fully offline, local private **multi-agent RAG assistant** optimized for AMD Radeon GPUs / ROCm.

**Pipeline:** Decompose → Parallel Research → Fact-Check → Synthesize. Every answer sentence is grounded against retrieved source text (per-sentence verification panel); every citation is checked against the knowledge base.

**AMD / ROCm:** multi-backend inference (llama.cpp HIP / Ollama ROCm / vLLM), GGUF quantization (Q4_K_M default ~4.6 GB VRAM), VRAM-shared model singletons, multi-agent parallelism to saturate the GPU, and a one-shot Radeon Cloud deploy script (`deploy_rc.sh`).
