# AI Learning Path Assistant Agent

## Track
Track 2 - Agentic AI

## Project Overview

AI Learning Path Assistant is an enhanced version of the Learning Path Dashboard.
It analyzes learner skills, tracks progress, and provides personalized learning
recommendations.

## Existing Project

Learning Path Dashboard for Enhancing Skills Using Python with Data Analytics.

## Features

- Skill assessment
- Learning progress tracking
- Personalized learning paths
- Analytics dashboard
- Course recommendations

## Technology Stack

- Python
- Flask
- MySQL
- Plotly
- HTML/CSS/JavaScript

## AMD Radeon GPU / ROCm Adaptation

The project is designed to support AI-based recommendation and inference
workloads accelerated using AMD Radeon GPUs and ROCm technologies.
