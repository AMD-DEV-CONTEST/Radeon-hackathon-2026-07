# Bloom

## Project Overview

Bloom is an AI-powered creative garden that transforms fragmented ideas into evolving digital plants.

The project combines multimodal AI interaction, visual creativity, and AI agent companionship to help creators capture, grow, and revisit their ideas through an interactive digital garden.

## Track

Track 1: Multimodal AI

## Key Features

- Multimodal idea input
- AI-assisted idea transformation
- Digital plant visualization
- AI Garden Keeper companion
- Interactive creative garden experience
