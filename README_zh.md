# 🎬 断脉 · AI剧本共创工作台（中文说明）

**[Back to English README →](README.md)** ｜ *AMD Radeon Hackathon 2026 · Track 2 – Agentic AI*

「断脉」是一个**带结构化长期状态**的 Agent 剧本共创工作台：用户与本地大模型以【问答+辅助+扩写】模式，走完 **点子→故事→大纲→剧本→脚本→分镜** 全流程。模型为 Qwen3.6-35B-A3B（Q8_0），通过 llama.cpp **100% 本地运行**在 AMD Radeon PRO W7900（ROCm/HIP）上，实测 ≈70 tok/s。

## 一、它解决什么问题？

普通 AI 写作工具是"无状态对话框"，聊到后面就忘设定。断脉把创作过程**状态化、可视化**：

- **永久记忆池**：铁律级设定（如"唐朝设定""怪物无智慧"），每次对话自动注入，AI 永不遗忘；
- **坑位看板**：未填/已填的悬念与逻辑坑，🪄 一键让 AI 填坑；
- **灵感高光墙**：自动捕捉用户的绝佳创意并上墙；
- **角色档案 / 伏笔追踪 / 情绪曲线**：全部注入 System Prompt，供逻辑自检对照；
- **阶段封存**：切换阶段自动定稿，AI 不可推翻前文；
- **注意力锚定词**：一键压缩"基石+记忆"，防长对话注意力稀释。

## 三、去AI味四件套（过检测方案）

1. **防**：🧼去AI味模式默认开 → 注入"人类编剧瑕疵铁律" + 高扰动采样（temp 1.15 / top_p 0.98 / presence_penalty 0.6）；
2. **治**：🧼深度拟人化改写（LLM 二遍改写，保留情节只改笔法）；
3. **治**：🧨物理洗稿（纯 Python 破坏标点/注入废笔/掐头去尾，不调 LLM）；
4. **测**：🧪AI味自测（爆发度+黑名单+连接词+直陈情绪 本地打分）+ 🔍高危句定位，人工只改 10~20% 高危句即可翻盘。

## 四、快速开始

```bash
bash setup.sh   # 依赖+模型下载+llama.cpp(ROCm)编译
bash start.sh   # 启动 llama-server + Streamlit + 穿透
```

## 五、AMD 优化清单

`GGML_HIP=ON / gfx1100`、`-ngl 999` 全量offload、`--flash-attn on`、`q8_0 KV cache`（48GB内开32K上下文）、`--threads 16`、显存经 torch.hip 设备级读取（多层兜底）。
