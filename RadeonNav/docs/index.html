01 · Overview

Route around what you cannot clear. Traverse what you can.

Locomotion skills and obstacle-avoidance planning are usually designed in isolation: the planner knows nothing about the skills’ capability limits, and the skill policy depends on hand-fed goals. RadeonNav connects a point-cloud planner to a frozen quadruped locomotion stack through the policy observation interface alone — no network is modified. Single-obstacle tests, run per terrain class on the deployed configuration, drive route construction: obstacles beyond the skills’ ability (the full-height bar hurdle) become planner-side virtual walls and are detoured, traversable terrain is crossed directly, and jump headings are frozen at skill entry so planner updates cannot disturb take-off. The only trained component is the depth encoder, fine-tuned in under 90 seconds on one AMD Radeon GPU.

02 · Built on three open-source projects

The stack

NeuPAN — planning core

Real-time point-cloud MPC with a learned distance field (DUNE). We add the waypoint envelope: reference-path construction, traversability costs, and receding heading feed. DUNE is ported to ROCm (identical outputs to 1.5×10−6, 5.65× faster forward). paper

Quadrupedal-agility — locomotion skills

Frozen skill selector and gait controller with natural gaits learned from canine motion capture, plus the depth encoder we fine-tune. Used exactly as released — our system changes only its observation channels. paper

UniLab — simulation framework

ROCm-native robot-learning framework (MuJoCo physics on CPU, policy tensors through HIP, headless EGL depth). Every task, sensor, and evaluation in this project is rebuilt and run inside it. paper

03 · Four strategies, same fixtures

Why the interface matters

Same frozen networks in every panel. The planner alone detours everything; the privileged teacher needs hand-authored goals and ground-truth labels; the original onboard student never arrives; ours traverses what is traversable and is the only configuration that knows not to jump the full-height hurdle.

04 · Reproduce

Two commands on an AMD GPU

$ bash setup/setup_rocm.sh && bash scripts/verify_environment.sh device AMD Radeon Graphics (gfx1100) torch 2.11.0+rocm7.2 · HIP runtime 7.2.26015 · MUJOCO_GL=egl
$ bash scripts/record_radeon-nav.sh [runner] 9 segments · planner 10 Hz · control 50 Hz [runner] reached goal → radeon_nav_full.mp4 + result.json $ jq .checks outputs/radeon-nav/latest/result.json all checks true — contract, finite rollout, video, no falls, no pedestrian collision, reached_goal
