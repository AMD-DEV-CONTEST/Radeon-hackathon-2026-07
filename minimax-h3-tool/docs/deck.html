Why this tool

Pain point
  • Video + audio generation needs cloud APIs or heavy NVIDIA stacks
  • Open-weights models (bf16) are 190 GB+ — won't fit consumer GPUs
  • Most tools do video or audio, rarely both, natively
Our answer
  • Omni-modal MiniMax H3: one sampling pass renders video + audio
  • pruned int8 set fits 48 GB VRAM on Radeon
  • 100% local & private — no cloud calls

Three generation modes

T2V

text prompt → video + stereo audio

Cinematic shots, narration, ambience

I2V

prompt + first/last keyframes → video + audio

Shot-constrained animation

R2V

prompt + reference images → identity-locked video + audio

Character / style reuse via <Picture 1>

Audio is native, not layered on: voice, sound effects and music are modeled jointly with the video in a single forward pass.

Local Studio · Streamlit UI (T2V / I2V / R2V tabs)3 / 10

System architecture

gradio/streamlit UI → ComfyUI API (8188) → MiniMaxH3 nodes
   → SamplerCustomAdvanced (joint video+audio latents)
   → VAEDecode (video) + VAEDecodeAudio (audio) → CreateVideo → mp4
Client — comfy_client.py builds prompt graphs, uploads keyframes, polls history, returns the mp4.
Server — ComfyUI native nodes on ROCm PyTorch; no CUDA code paths.

Models: pruned int8 fl2va/ref2va (~21 GB) · int8 Qwen3-VL-32B (27 GB) · fp16 video VAE + fp32 audio VAE

Hardware: AMD Radeon PRO W7900 · gfx1100 · RDNA3 · 48 GB4 / 10
