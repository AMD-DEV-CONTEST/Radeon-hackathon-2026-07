## 全片结构（VOX 分镜）

### Beat 0 · 钩子（0:00–0:25）

**画面**：黑场 → 一行字「交付，为什么总是不满意？」→ 碎成六个需求色块。

**口播**：

> 大多数 AI 产品从模型往下堆功能。omima 反过来——从**六大类应用需求**往上长算法，再收敛成一套完整的**效率工程**。

---

### Beat 1 · 六大类需求（0:25–1:20）

**画面**：六宫格依次点亮，每格一词 + 微图标。

| 格 | 文案 |
|----|------|
| 1 | 基础能力 |
| 2 | 推理与科学 |
| 3 | 对话与创作 |
| 4 | 知识与百科 |
| 5 | 安全与责任 |
| 6 | 长文本与 Agent |

**口播**：

> 基础调用、科学推理、创作对话、知识沉淀、安全责任、长程 Agent——用户真正要的是这六类结果，不是又一个聊天壳。  
> 需求定了，系统该长什么协议、什么模型岗位、什么工序，才被推导出来。

**动效**：六格收束成一条箭头：「需求 → 实现算法」。

---

### Beat 2 · 三大要素（1:20–3:10）

**画面**：三根立柱并立，标题「收敛」。

#### 柱 1 · 系统化协议与算法

**画面**：星轨 / 登记·调用·记忆·铁律·回传·移交 六段短环；越权路径红灯 DENY。

**口播**：

> 第一要素：**系统化协议与算法**。谁入网、怎么调、记忆归谁、何时拦截——写成类型约束的协议与算法。协作可复制，边界可执行，状态可回放。

#### 柱 2 · 内化大模型的设置

**画面**：1B / 9B / 35B 三岗胸牌；「路由·工具·军师」；旁注 MI300X 小字「训练与验证底座」。

**口播**：

> 第二要素：**内化大模型的设置**。1B 守记忆与路由，9B 跑工具循环，35B 扛深推理——岗位内化，不是买个通用权重碰运气。训练与量化是上岗手段。

#### 柱 3 · 内化的工作方法

**画面**：五拍时间轴横向展开，多条 Agent 轨串行衔接、局部并行：

```text
创意 → 论证 → 规划 → 执行 → 审查
  ║      ║      ║  ══╪══  并行星站
  串流不跳拍          执行面可并
```

**口播**：

> 第三要素：**内化的工作方法**——创意、论证、规划、执行、审查。多 Agent **串流并行**：该串的不跳拍，能并的一起跑。每一步留下可审计产物。这就是 Loop 工程——循环有边界，不是 while true。

**动效**：三柱合拢，中央出现「高满意度交付」。

---

### Beat 3 · 效率工程三切面（3:10–4:20）

**画面**：三角形或三层环：

```text
        Harness
       ／        ＼
   Loop 工程 —— 硬件编制
```

**口播**：

> 整套东西是**效率工程**，不是单点技巧。  
> **Harness**——工具如何被约束、经验如何累积、路径如何复用。  
> **Loop 工程**——多步如何不失控、串并行如何编排、审查如何闭环。  
> **硬件**——算力与隐私落在哪：端侧与星罗棋布，岗位对硅片。  
> 三者一起规划，才叫完整。

**可选 8 秒**：成本账一行小字「缓存命中：重复推理不重复付满价」（不抢主叙事）。

---

### Beat 4 · 一次任务走完（4:20–5:40）

**画面**：抽象任务卡片进入系统 → 五拍着色 → 星站并行小点 → 铁律闪断一次红灯 → 交付物图标落盘。

**口播示例任务**（中性）：

> 用户要一份可审计的方案摘要并写入私库。  
> 创意收集材料，论证定边界，规划拆步，执行派星站与工具，审查对照目标。  
> 记忆留在阵眼；出站的是任务，不是隐私上下文。  
> 交付的是走完工序的结果——不是一句话生成碰运气。

---

### Beat 5 · AMD / 硬件切片（5:40–6:30）

**画面**：硬件图谱简图 + 数字卡片（信息图，非必须实机）：

- FP8 vs BF16：+65%  
- tool-call 8/9  
- 岗位权重在 Instinct 上训出  

**口播**：

> 硬件编制落在 AMD 分层产品上：训练与军师验证在 MI300X，岗位权重可复核。  
> 测速与微调是要素二的工程切片——中规中矩，服务上岗。

---

### Beat 6 · 收束（6:30–7:00）

**画面**：六需求 → 三要素 → 交付，循环一圈定格 slogan。

**口播**：

> 六大类需求推导实现；三大要素收敛系统；Harness、Loop、硬件同一套效率工程。  
> omima —— Order Made In Mayhem, Always.  
> 秩序，总从混乱中生成。

## 制作规格（VOX）

| 项 | 建议 |
|----|------|
| 画幅 | 16:9，1080p 或以上 |
| 风格 | 深色底、少量信号色、信息图动效（可对标 VOX 解说节奏：快切概念、少 UI 实操） |
| 字幕 | 关键词打板：六大类 / 三要素 / 五拍 / Harness·Loop·硬件 |
| 音乐 | 低音量电子/氛围，不压口播 |
| 时长 | 主片 5–7 分钟；可另附 30s 超短版只含三要素 |
| 素材 | 图标、流程图、数字卡；魔搭链接可片尾静帧 |
