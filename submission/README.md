# ClaimCourt Submission Package

This directory contains the English competition deliverables for Team Zi Fei Yu.

- `PROJECT_DESCRIPTION.md`: source for the formal project description.
- `ClaimCourt_Project_Description.docx`: generated editable document.
- `ClaimCourt_Project_Description.pdf`: required judge-facing project description.
- `ClaimCourt_Presentation.pptx`: required presentation material.
- `DEMO_SCRIPT.md`: 4-minute 20-second recording script.
- `PR_BODY.md`: English Pull Request description.
- `SUBMISSION_CHECKLIST.md`: final release gate.
- `assets/claimcourt-ui.png`: locally rendered English product interface.

Demo video: https://youtu.be/Do_LJsUSFnQ

The demo video URL must be added to `PR_BODY.md` before the official Pull Request is opened.
