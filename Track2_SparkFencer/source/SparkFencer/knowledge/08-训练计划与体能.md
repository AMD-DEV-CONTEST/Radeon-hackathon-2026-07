# 训练计划与体能

## 周期化框架
- 准备期(赛前 8-12 周):体能与基本功比重大,步法量大、低强度长时间。
- 强化期(赛前 4-8 周):专项技术+战术组合,实战课比例上升。
- 赛前期(1-4 周):高强度模拟实战、降量保质,重点打磨得分手段与针对性战术。
- 赛后恢复期:低强度有氧+技术纠错复盘。

## 单次训练课结构(90-120 分钟)
热身与专项激活 15' → 步法 20'(质量优先于数量) → 技术课/个别课 30'(教练喂招) → 条件实战 20'(限定得分方式) → 自由实战 15' → 拉伸放松 10'。

## 击剑专项体能
- 下肢爆发:蹬伸功率决定弓步速度——跳箱、蹲跳、单腿硬拉。
- 弓步耐力:比赛后段技术变形多源于股四头肌与臀肌耐力不足——弓步行走、耐力循环。
- 前臂与腕:控剑精度基础——腕绕环、握力器、剑尖画圈(米字/绕点)。
- 能量系统:击剑是间歇性爆发项目,以 10-30 秒高强度 + 短恢复的间歇跑最贴合专项。

## 用数据驱动训练重点
| 数据信号 | 优先安排 |
|---|---|
| 弓步恢复时间 > 0.8s | 弓步还原循环 + 后链力量 |
| 后段峰值速度明显下降 | 专项间歇体能 |
| 先动率低且反击少 | 时机与勇气练习(条件实战:只有主动进攻得分才算分) |
| 交锋距离方差大 | 双人镜像控距练习 |
