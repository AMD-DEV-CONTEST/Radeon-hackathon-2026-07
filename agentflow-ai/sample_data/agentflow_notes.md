# AgentFlow AI Sample Notes

Use this file to test local document ingestion.

## Key capabilities
- Planner Agent creates task breakdowns.
- Research Agent retrieves local evidence from ChromaDB.
- Memory Agent recalls SQLite conversation history.
- Tool Agent runs safe offline utilities.
- Reviewer Agent improves answer quality before final delivery.

## Demo angle
This platform is designed for hackathon demos where judges need to *see* autonomous orchestration, not just chat replies.
