## 5. 配音稿全文

大家好，我是 qiancy，AMD Developer Program 编号 00000657。这个作品叫 UR-Agent，全名 Uni-Resource Agent，参加 2026 AMD AI DevMaster 黑客松 Track 2，方向是私有 AI Agent 开发与本地部署。

UR-Agent 的核心理念是 Everything is a Resource。它把个人、家庭、小型组织和经营场景中的资产、知识、人员、财务流水、商品和任务统一抽象成资源，让 Agent 可以在本地环境中检索、分析和执行。

首先看运行环境。这里使用 AMD Radeon GPU 和 ROCm，核心大模型通过 llama.cpp ROCm 后端运行，并暴露为本地 OpenAI-compatible API。FastAPI 后端、数据库、向量检索和前端界面都部署在本地，不依赖远程闭源 Agent 平台处理核心数据。

现在演示本地知识库能力。我把一段项目资料写入当前空间知识库，然后直接询问它的核心价值。Agent 会先在当前组织空间的知识集合中做检索，再结合本地模型生成回答。这说明私有资料可以保留在本地，同时支持 RAG 问答。

接下来演示工具调用和多步骤规划。我输入一个复合任务，让 Agent 查看当前空间里的资源、财务和知识记录，找出风险并生成行动清单。Agent 会根据任务自动选择工具，先读取结构化数据，再结合知识检索结果，最后给出可执行建议。

然后继续追问，让它把刚才的行动清单压缩成今天下午可以完成的三件事。这里展示的是本地多轮记忆，Agent 能理解上一轮上下文，而不是把每次提问都当成孤立任务。

最后切换到另一个空间，例如 Seller 空间。UR-Agent 使用 JWT 中的 puid 和 ouid 绑定人员与组织空间，每次工具调用都会按当前空间过滤数据，所以不同空间之间不会串线。这是私有 Agent 落地时很重要的权限和隐私边界。

在性能方面，项目使用 GGUF 量化模型、ROCm GPU offload、上下文裁剪、向量索引和工具返回字段控制，降低显存占用并提升响应速度。最终实测的 GPU 型号、ROCm 版本、tokens per second 和端到端耗时会记录在提交材料中。
