# web/

前端页面（原生 HTML/CSS/JS，无构建步骤，P2 已实现）。

## 功能

- 工作流选择（W1 概念原画 / W2 深度图）
- 动态参数表单（prompt、seed、尺寸、步数、CFG 等）
- 图片上传 或 选择服务器已有图片（输入目录 / 历史输出目录，可刷新）
- 任务列表 + 状态轮询（2 秒一次）
- 结果预览与下载

## 说明

页面由后端 `server/app/main.py` 直接托管（`/` 与 `/static/*`），
无需单独部署。后续如需更丰富的交互，可迁移到 Vue/React + Vite，
接口不变。

## 3D 场景页（自动演出）

`scene.html?batch=…`：环境照片（W1 概念图 + W2 深度图）立体化为 3D 场景，
W7（TripoSR）把 2D 角色图转成真正的 3D 模型（GLB）放入场景；
未生成模型时用内置低模酒保演示。

- 自动演出：走进酒吧 → 吧台喝酒 → 巡桌小酌 → 回吧台听音乐（无需操控）
- 举杯时触发玻璃杯音效；背景音乐 / 环境音自动循环
- 交互：点击开启声音；镜头自动缓慢旋转，可拖拽 / 缩放
- WebGL 不可用时自动降级为纯 Canvas 2D 模式
