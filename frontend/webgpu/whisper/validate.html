Whisper-tiny encoder — WebGPU kernel validation

Runs the float16 WebGPU encoder against activations captured from PyTorch, and against a CPU transcription of the same kernels. The two comparisons answer different questions: GPU vs CPU should match to f32 rounding — a gap there is a WGSL or driver bug. GPU vs torch should match to the same rounding, because f16 storage of an fp16 checkpoint is lossless — a gap there is a math problem. Three checkpoints are compared rather than one, so a broken mel frontend cannot be confused with a broken attention block. Serve this over HTTP (python3 -m http.server); file:// will not load ES modules.
