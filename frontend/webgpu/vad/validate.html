Silero VAD — WebGPU kernel validation

Runs the int8 WebGPU pipeline against vectors captured from ONNX Runtime, and against a CPU transcription of the same kernels. The two comparisons answer different questions: GPU vs CPU should match to f32 rounding — a gap there is a WGSL or driver bug. GPU vs ONNX should match to the int8 budget — a gap there is a quantization problem. Serve this over HTTP (python3 -m http.server); file:// will not load ES modules.
