# 首用引导与浅色主题技术设计

- Level: S2
- Status: implemented

## 改动

- 新增纯前端 `getReportReadiness`：读取当前项目文件和任务数，仅在浏览器中给出前置提示；服务端仍会执行正式校验。
- 在报告按钮点击时并行读取文件和任务，缺资料或任务时不创建运行。
- Material library 在浏览器生成 CSV 模板下载，不写入服务器目录。
- 将颜色 token 改为浅色方案，并保留状态色与边框对比度。

- 单元测试覆盖：缺参考资料、上传任务表、任务工作台已有任务三种前置条件。
- 运行 TypeScript 检查、前端测试、生产构建和严格 Spec 校验。
