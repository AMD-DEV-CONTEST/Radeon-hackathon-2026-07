# 首用引导与浅色主题

- Level: S2
- Status: implemented

## 用户问题

新用户登录后不知道为什么没有项目、需要上传什么资料，或在缺少资料/任务时才发现报告运行失败。深色界面对办公用户的可读性也较弱。

## 目标

1. 空项目列表时，直接说明下一步是创建项目；
2. 创建项目入口在首次使用时自动展开；
3. 上传区提供任务 CSV 模板；
4. 发起报告前提示缺少资料或任务，而不是浪费一次运行；
5. 将 Web 工作台改为浅色、高对比度主题。

## 非目标

- 不改变后端权限、项目隔离或 RAG 执行顺序；
- 不把自然语言任务提取直接写入正式任务；
- 不把模型、云端状态伪装为本地已验证。
