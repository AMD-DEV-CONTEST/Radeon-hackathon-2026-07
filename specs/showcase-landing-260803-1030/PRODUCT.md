# Product: Project showcase landing page

## Goal

Provide a concise, public-facing landing page that explains the ProjectPack Office Agent value proposition before a reviewer enters the authenticated workbench.

## User outcomes

- A reviewer can understand the problem, controlled workflow, and generated outputs in one screen flow.
- A reviewer can see the AMD Radeon / ROCm role without requiring access to project data.
- The page links to the repository and does not claim that unavailable live integrations are active.

## Scope

- Add an independent static page under `showcase/`.
- Include responsive desktop and mobile layout.
- Include only product claims supported by the repository and recorded cloud benchmark.

## Non-goals

- This is not a replacement for the authenticated workbench.
- This change does not add analytics, external assets, or a production hosting provider.
