拒绝未验证的完成叙事

Local Dev Evidence Agent（LDEA）是本地开发证据智能体： 不复述聊天，只回答「到底做成了什么」。 只有 status=verified 才能写已完成——大模型不能自证。

问题 AI 说「已修复」与空口「今天全做完」廉价且不可核验。
方法 git / 测试 → L0–L1 账本 → 确定性报告。
