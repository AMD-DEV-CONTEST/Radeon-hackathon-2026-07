Smart Curriculum Activity and Attendance App

Track: Track 1 – Development of Multimodal Content Creation Tools

Team Name: Kowsalyabala25
Location: Dharapuram, Tamil Nadu, India

Project Overview

Smart Curriculum Activity and Attendance App is an AI-powered educational platform designed to digitize and automate academic operations in schools and colleges. The system combines intelligent attendance management, AI-based curriculum planning, activity monitoring, and automated reporting to reduce administrative workload and improve learning outcomes.

Key Features

1. Smart Attendance System

- Automates attendance marking using AI-based face recognition technology.
- Reduces manual errors and saves valuable classroom time.
- Provides real-time attendance records for faculty and administrators.

2. AI Curriculum Planning Assistant

- Analyzes syllabus requirements and student performance.
- Recommends suitable lessons, activities, and learning strategies.
- Helps teachers create personalized learning experiences.

3. Activity Tracking System

- Maintains records of curricular and extracurricular activities.
- Allows faculty to monitor student participation and progress.
- Provides centralized management of academic activities.

4. Intelligent Reports and Analytics

- Generates automated attendance and performance reports.
- Provides insights for administrators, teachers, and parents.
- Supports data-driven academic decisions.

AMD GPU Acceleration

The application is designed to utilize AMD Radeon GPUs with ROCm acceleration for efficient AI model training and inference. GPU optimization improves the performance of computer vision models used in face recognition and AI recommendation features, enabling faster and more scalable educational automation.

Innovation

Unlike traditional attendance and management systems, this platform integrates multiple AI-powered modules into a single solution:

- Computer Vision for attendance automation
- AI recommendations for curriculum improvement
- Automated analytics for better decision-making

Impact

The solution helps educational institutions:

- Reduce manual workload for teachers
- Improve attendance accuracy
- Enhance student engagement through personalized learning
- Enable data-driven academic planning
- Improve communication between institutions and parents
