# torch AND torchvision are installed per-platform, not from this file. Both are
# required: hy3dgen imports torchvision at import time. They are deliberately NOT
# listed as plain requirements — a bare `torchvision` resolves against PyPI and
# would drag the default CUDA/CPU torch wheel onto a ROCm machine, shadowing the
# container's ROCm build.
#   AMD ROCm : pip install torch torchvision --index-url https://download.pytorch.org/whl/rocm7.2
#              Swap rocm7.2 for the index matching your ROCm install — rocm6.2,
#              6.3, 6.4, 7.0 and 7.2 all publish wheels. Easiest path is the
#              rocm/pytorch docker image, which ships both — see docker/Dockerfile.rocm
#   NVIDIA   : pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
