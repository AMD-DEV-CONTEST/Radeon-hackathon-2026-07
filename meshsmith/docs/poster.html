The gap it closes

Image→3D models make impressive meshes that fail at the point of use: not watertight, no UVs, no physical scale, floating debris, orientations that drown FDM prints in support material. MeshSmith is the missing last mile — from "look at this mesh" to "here is the STL your slicer accepts."

Who it's for

  • 3D-printing hobbyists — prompt → knob, bracket, figurine. No CAD.
  • Indie game devs — props with sane topology, UVs, PBR materials.
  • Makerspaces & schools — no API fees, data stays on-device, and the report teaches printability.

Built for ROCm, not ported to it

  • Zero vendor-specific code — GPU stages use the portable torch.cuda API; ROCm maps it to HIP.
  • Shape-only Hunyuan3D by design — skips the custom CUDA texture rasterizer, so install is pure pip in any rocm/pytorch container.
  • fp16 + lazy load/unload — fits 16 GB cards.
  • ROCm Dockerfile + one-command Radeon Cloud setup.
  • Observable — per-stage wall time & peak VRAM in every report.
