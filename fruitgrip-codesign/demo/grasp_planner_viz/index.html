How this works

For the selected object + design, the planner slices the object's own mesh at many heights, and at each height looks for the points whose outward surface normals most directly oppose each other (2-finger) or point radially outward together (N-finger) — subject to fitting the design's real aperture.

This is the exact computation the controller uses when routing grasp targeting through the planner instead of the fixed per-object heuristic — not a separate illustrative version.
