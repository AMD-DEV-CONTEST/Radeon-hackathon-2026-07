# 评委演示流程

> 照着这个走，5 分钟讲完，不慌不漏。

## 演示前准备（提前做）

1. 确认 `radeon` provider 的 API Key 有效（去 [Token Factory](https://developer.amd.com.cn/radeon/modelapis) 检查）。
2. 如果有 ComfyUI 在 Radeon 实例上跑，确认 SSH 隧道连着。
3. 确认公众号 AppID/AppSecret 填了（发草稿箱要用）。
4. **提前生成 1-2 篇文章存好**（万一现场网络慢，直接展示历史记录里的成品）。

## 演示流程（5 分钟）

### 第 1 步：产品介绍（30 秒）

打开应用 → 自动展示介绍页（`/demo`）：
- 念 tagline：「照片 + 主题 → 一键生成公众号文章 + 小红书笔记 → 发草稿箱，全程 AMD GPU」。
- 指一下赛道四评分点（推理加速 / 轻量化部署 / 风格定制 / 画质优化）。
- 如果 ComfyUI 连着，指一下「GPU 状态」区域（显示 AMD 显卡型号 + 显存）。

### 第 2 步：生成一篇文章（2 分钟）

点「立即体验」→ 进入主页：
1. 输入主题（如「Radeon GPU 性能实测」）。
2. 上传 2-3 张截图。
3. 每张照片选个风格（如动漫），或选「无」。
4. 选模板（如「产品评测」）。
5. 点「一键生成」。

> 观察进度条：「正在写文章 10%（已等 45s）」——秒数在涨 = 在跑。
>
> **如果太慢**：直接打开历史记录，展示提前生成好的文章（说「这是之前在 AMD GPU 上生成的」）。

### 第 3 步：展示结果（1.5 分钟）

预览页打开后：
1. **封面**：顶部 AI 生成的 2.35:1 卡片封面（如有 ComfyUI）。
2. **标题 + 摘要**。
3. **正文**：图文穿插——指出来「这张 3DMark 截图被自动放到了讲 3DMark 的段落旁边，视觉模型看懂了图上的字」。
4. **图注**：每张图下面有 AI 写的图注。
5. **计时**：「文本用了 Xs，出图用了 Ys」。
6. **可编辑**：点进去改几个字、拖动一张图——「生成后可以编辑」。

### 第 4 步：发草稿箱（30 秒）

点「发到公众号草稿箱」：
- 弹出 `media_id` = 成功。
- 「这篇文章已经进了我的公众号草稿箱，登录后台就能看到、编辑、发布。」

### 第 5 步：收尾（30 秒）

- 点「重新生成」展示「不满意可以再跑一次」。
- 打开历史记录页展示「之前生成的文章都存着」。
- 一句话总结：「Content Studio 把 AI 写文、AMD GPU 风格化出图、视觉智能放图、公众号直发，串成了一个完整的多模态内容创作流水线。」

## 常见问题应答

| 评委可能问 | 回答要点 |
|---|---|
| AMD GPU 用在哪了？ | 文本：Radeon Cloud（Qwen on AMD GPU）；图像：ComfyUI on ROCm（AMD GPU 风格迁移 + 文生图）。 |
| 和直接用 ChatGPT 有什么不同？ | ①看图放图（视觉理解）②照片风格化（ComfyUI AMD GPU）③直发草稿箱（API）④可编辑预览⑤小红书也做⑥AMD GPU 全链路。 |
| 为什么用 Radeon Cloud？ | 赛方提供，免费共享 API 开箱即用；专属 vLLM 实例独占 GPU 更快。 |
| 风格化怎么做？ | ComfyUI img2img（DreamShaper 8），denoise 0.55，保留构图换风格。8 种预设 + 可自定义 workflow。 |
| 怎么部署给别人用？ | FastAPI 服务端 / PyWebView 桌面应用 / 详见 ROCm 迁移指南。 |
