Content Studio

AI-Powered Multimodal Content Creation Tool on AMD Radeon GPU + ROCm

2026 AMD AI DevMaster · Track 1

1. Project Background

Content creators on Chinese social media (WeChat Official Accounts, Xiaohongshu/RedNote) face a repetitive, multi-step workflow: write articles, style photos, place images, format per platform, and manually publish. No existing tool integrates AI text generation, image styling, intelligent placement, and direct publishing into one pipeline — especially one powered by AMD Radeon GPU + ROCm.

Content Studio fills this gap. Users upload photos, type a theme, and get a complete article with AI-styled images logically placed — all on AMD GPU infrastructure.

3. System Architecture

Web UI (FastAPI + Jinja2 + PyWebView)
  ├── Text Generation ──→ Radeon Cloud API (AMD GPU)
  │                        ├── Free shared: Qwen3.6-35B-A3B
  │                        └── Dedicated vLLM: Qwen2.5-VL-7B-Instruct
  ├── Image Generation ──→ ComfyUI on ROCm 6.2 (AMD GPU)
  │                        ├── Style Transfer (img2img, DreamShaper 8)
  │                        └── Text-to-Image (txt2img, custom prompts)
  ├── Vision Understanding → Model reads photos → logical image placement
  └── Publishing ────────→ WeChat Official Account /draft/add API

Key design: core/ is UI-independent (92 tests). All services communicate via HTTP — mockable, replaceable. Switching LLM models = change config, not code.

4. Model & Algorithm

4.1 Text Generation

  • LLM: Qwen3.6-35B-A3B (Radeon Cloud) — 1000+ word articles with structured JSON output
  • Robust parsing: Code-fence stripping, prose extraction, repair re-request, raw fallback
  • Templates: Product review, event promo, tutorial, industry analysis

4.2 Image Style Transfer (img2img)

  • Engine: ComfyUI + DreamShaper 8 on AMD GPU (ROCm 6.2, gfx1100)
  • Workflow: LoadImage → VAEEncode → KSampler (denoise 0.55, 20 steps) → VAEDecode
  • 8 presets: anime, cyberpunk, watercolor, retro, minimal, oil, ink wash, pixel art

4.3 Text-to-Image (txt2img)

  • Engine: ComfyUI + DreamShaper 8, EmptyLatentImage 512×512, 22 steps
  • Custom prompts: User writes English descriptions (one per line), ComfyUI renders each

4.4 Vision-Based Image Placement

  • Model: Qwen3.6-35B reads each photo's content → places [[IMG:k]] markers at relevant sections
  • Fallback: Converts Chinese "图N" references; distributes unplaced images after section headers

4.5 WeChat Draft Publishing

  • access_token cached (auto-refresh); body images via /media/uploadimg; cover via /material/add_material; draft via /draft/add
  • 40001 token expiry → invalidate + retry once

6. Innovation Highlights

  1. Vision-driven image placement: Model reads photo content → places each image beside the most relevant paragraph
  2. Custom t2i prompts: User specifies what ComfyUI should draw — full creative control
  3. Auto-detect vision capability: Falls back to text-only if model doesn't support images
  4. Direct API publishing: One click → complete article in WeChat draft box
  5. Dual-platform output: WeChat articles + Xiaohongshu posts from same input
  6. Graceful degradation: ComfyUI down → original photos; LLM slow → clear status with elapsed timer
