## Aim of the Project
Create a modular robotics AI workflow using RoboTiago, Docker, FastNCP, and the Qwen open-source model via Hugging Face API.

## Tools Used
- RoboTiago robot
- Docker containerisation
- FastNCP accelerated inference
- Qwen model (Hugging Face API)
- Python + ROS/ROS2

## Results
- Reduced inference latency
- Stable robot–AI communication
- Reproducible deployment using Docker
- Improved perception and decision-making accuracy
