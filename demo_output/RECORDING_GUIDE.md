# Demo 录制指导（B 方案：你本地录，Agent 后期合成）

目标：3–5 分钟 mp4，含真实 GPU 功耗画面 + 英文字幕。
本机 ffmpeg 已就绪，你只需录原始画面，字幕/片头/角标由 Agent 烧录。

## 录制前准备
1. 在 GPU 服务器上重启 WebUI：`scripts/restart_webui.sh`，确认 `:7860` 起来。
2. 打通隧道：`ssh -L 7860:localhost:7860 user@host -p PORT`，浏览器开 `http://localhost:7860`。
3. 开一个终端，常驻显示功耗（录的时候要让它出现在画面里）：
   - `watch -n1 'rocm-smi --showpower'`  或
   - 后台日志：`rocm-smi --showpower -f power_log.csv --repeat 300`（Agent 后期可画曲线）
4. 录屏软件：OBS / Bandicam / 或 `ffmpeg -f gdigrab -i desktop out.mp4`。
   建议把「浏览器窗口」和「功耗终端」并排放在同一画面（分屏），分辨率 1920×1080 最佳。
5. 关闭无关通知/桌面图标，保持画面干净。

## 录制小贴士
- 每段之间可停顿，Agent 后期会按字幕对齐裁剪，不必一次过。
- 功耗终端务必全程在画面内（这是 AMD ROCm 卖点的核心证据）。
- 出图慢没关系，真实等待反而更可信；9.4s/img 是正常速度。
- 录完把原始视频（任意格式）发我，并告诉我每段大概从几分几秒开始，我据此烧录字幕。
- 字幕提供英文 `subtitles_en.srt` 与中文 `subtitles_zh.srt` 两版（时间轴一致）；要中英双语烧录也行，告诉我即可。

## 交付后 Agent 会做

- 叠加功耗角标（16W→212W）与「9.4s/img」数据条。
- 加片头/转场，导出 1920×1080 mp4。
